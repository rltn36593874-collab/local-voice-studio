## 0. 범위와 근거

- **앱 관찰**: 2026-11-21, 사용자 크롬 로그인 계정, 한국어 UI. 새 탭을 따로 열어서 봤고 끝난 뒤 닫았다.
  - 본 화면: `/app/home`, `/app/speech-synthesis/text-to-speech`, `/app/create-voice`, `/app/create-voice/instant`, `?creationType=voiceDesign`, `?creationType=voiceRemix`, `/app/speech-synthesis/speech-to-speech`, `/app/dubbing`, `/app/studio`, `/app/voice-library`
- **공식 문서**(문서에 적힌 내용만 옮김. 표에는 [문서]로 표시):
  - TTS `docs/eleven-creative/playground/text-to-speech`
  - IVC `.../voices/voice-cloning/instant-voice-cloning`
  - PVC `.../voices/voice-cloning/professional-voice-cloning`
  - Voice Design `.../voices/voice-design`
  - Remix `docs/overview/capabilities/voice-remixing`
  - Voice Changer `.../playground/voice-changer`
  - Dubbing `.../products/dubbing`, `.../products/dubbing/dubbing-studio`
  - Studio `.../products/studio`
  - Voice Library `.../voices/voice-library`
  - 공통 앞부분은 `https://elevenlabs.io/docs/` 이다.
- **누르지 않은 것**: 생성·변환 버튼, 녹음, 업로드, 프로젝트 생성, 결제, 설정 변경은 하지 않았다.
- **로컬 조작으로 그친 것**:
  - TTS 입력창에 임시 글자를 넣어 하단 바를 확인한 뒤 지웠다.
  - 화자 블록을 추가해 봤다(저장 안 함).
  - 드롭다운과 팝오버를 열었다 닫았다.
- **상태가 바뀌었을 수 있는 것**: 더빙 첫 진입 때 뜬 "Dubbing v2 alpha 소개" 모달을 "시작하기"로 닫았다. 이 때문에 '봤음' 표시가 저장됐을 수 있다(확인 못 함).
- **표기**: 이 문서의 UI 문구 인용은 관찰 기록일 뿐이다. 우리 제품에 그대로 쓰지 않는다(6장 참고).

## 1. 전체 레이아웃 패턴

```
┌────────────┬──────────────────────────────────────────────────────────────┐
│ 왼쪽 내비   │ [프로모 배너 — 닫기 가능, 전 화면 공통]                          │
│            ├──────────────────────────────────────────────────────────────┤
│ 로고        │ 헤더: [사이드바 접기][브레드크럼/화면명]  [전역 검색 ⌘K]  [피드백][문서][질문][자산][알림][프로필] │
│ ─ 1차 메뉴  ├───────────────────────────────────────┬──────────────────────┤
│ 홈/음성/    │                                       │ 오른쪽 패널(일부 화면) │
│ 스튜디오/   │        가운데 작업 영역                  │ 탭: 설정 | 기록        │
│ 흐름/Producer│        (화면 유형별로 아래 A~E)          │ 접히는 섹션들          │
│ /앱/자산    │                                       │ 프로모 카드(닫기)      │
│ ─ 고정 도구 │                                       │                      │
│ (핀 해제 가능)│                                      │                      │
│ ─ 더 많은 도구▸│                                     │                      │
│ ─ 하단: 초대카드│                                    │                      │
│ MCP·API/플랫폼│                                     │                      │
│ 전환/구독    │                                       │                      │
└────────────┴───────────────────────────────────────┴──────────────────────┘
```

### 1-1. 왼쪽 내비 (확인함)

- 1차 메뉴: 홈, 음성, 스튜디오, 흐름, Producer, 앱, 자산.
  - '음성'에 호버하면 "음성 만들기" + 버튼이 나온다.
- "고정" 그룹: 텍스트 음성 변환, 음성 생성, 효과음, 이미지 및 비디오, 보이스 아이솔레이터, 보이스 체인저, 뮤직, 음성 텍스트 변환, 더빙, 오디오북.
  - 항목마다 "고정 해제" 버튼이 있다. 사용자가 즐겨찾기처럼 직접 고르는 구조다.
- "더 많은 도구" 플라이아웃: 템플릿, 오디오 네이티브, 프로덕션, Ads 엔진. 각 항목에 '고정' 동작이 있다.
- 하단: 팀 멤버 초대 카드(닫기 가능), MCP 및 API, 플랫폼 전환기(현재 표시는 'ElevenCreative'), 구독.

### 1-2. 상단 (확인함)

- 사이드바 토글, 화면명 또는 브레드크럼(예: 음성 생성 › 즉시 음성 복제).
- 전역 검색 "모두 검색..."과 단축키 힌트.
- 우측 아이콘 버튼: 피드백, 문서, 질문, 자산, 알림, 프로필.
- 최상단에 전 화면 공통 프로모 배너가 있다.

### 1-3. 가운데 작업 영역 유형

| 유형 | 구조 | 쓰는 화면 |
|---|---|---|
| A. 편집기 + 오른쪽 설정 패널 | 가운데에 입력(텍스트·오디오), 하단에 고정 액션 바, 오른쪽에 설정과 기록 탭 | TTS, 보이스 체인저 |
| B. 허브 카드 그리드 | 큰 카드 3개(설명, 시각물, CTA)와 '기타 도구' 가로 카드 | 음성 생성 |
| C. 프롬프트 바 + 목록 | 상단 입력 컴포저, 바로가기 카드나 캐러셀, 그 아래 검색·필터칩·정렬·보기전환이 있는 목록 | 홈, 스튜디오, 더빙 |
| D. 집중 생성 화면 | 모달(보이스 디자인) 또는 닫기 X가 있는 전체화면 오버레이(리믹싱) | 음성 생성 하위 |
| E. 브라우저(라이브러리) | 탭, 검색, 필터·정렬, 카테고리 칩, 카드 그리드, 큐레이션 캐러셀 | 음성 라이브러리 |

### 1-4. 오른쪽 패널 (TTS·보이스 체인저에서 확인함)

- 탭은 "설정 | 기록" 두 개다.
- 설정 섹션은 제목 옆 꺾쇠로 접힌다.
- 모델 선택은 팝업이 아니라 **패널 안에서 화면이 바뀌는 방식(드릴인)**이다. 뒤로가기 화살표로 돌아온다.
- 편집기에 화자를 추가하면 패널이 '설정' 탭으로 자동 전환되는 것을 봤다.

## 2. 핵심 화면 정보구조

### 2-1. 텍스트 음성 변환 `/app/speech-synthesis/text-to-speech` (유형 A)

```
가운데 편집기
├─ 화자 블록 ×N
│   ├─ 화자 칩(음성 이름) → 클릭하면 음성 선택기
│   ├─ 블록 삭제 X (글이 있을 때 보임)
│   └─ 텍스트 입력 (플레이스홀더에 오디오 태그 사용 안내)
├─ "화자 추가" 구분선 버튼 (블록 사이·끝) → 블록 추가 = 다화자 대화
├─ [빈 상태] '시작하기' 예시 칩 6개
└─ 하단 액션 바 (글을 입력해야 나타남, 빈 상태에서는 안 보였음)
    ├─ 남은 크레딧 "10,000 크레딧 남음"
    ├─ 글자 수 "3 / 100,000 문자"
    ├─ "자동 태그" 분할 버튼 + ▾ → 태그 선택기(검색, 그룹: 감정·음성 표현·행동 …)
    └─ [음성 생성] 주 버튼   ← 누르지 않음

오른쪽 패널
├─ 탭 [설정] [기록]
├─ 설정
│   ├─ 음성: 선택 행(아바타+이름) ▸, 우측 "추천" 링크
│   ├─ 모델: 선택 행 ▸ → 패널 안 드릴인 "모델 선택"
│   │     카드 = 모델명, 설명, 지원 언어 칩(+N개 더), 현재 선택 ✓,
│   │     "추천 대상: <음성>" 행, 맨 아래 "모든 모델 보기"
│   ├─ 안정성 슬라이더 50% (창의적인 ↔ 견고한)
│   ├─ 유사성 슬라이더 75% (낮음 ↔ 높음)
│   ├─ 언어: 접힌 상태 "자동" → 펼치면 드롭다운 "자동 (권장)"
│   ├─ 오디오 효과: "효과 추가" 버튼
│   └─ 출력 형식 드롭다운
│         MP3 44.1kHz 128kbps(기본) / 192kbps,
│         WAV 8·16·22.05·24·44.1·48kHz(무손실)
│         일부 항목이 흐리게 보임(비활성 사유 확인 못 함, 요금제 제한 추정은 하지 않음)
└─ 기록: 빈 상태 = 아이콘 + "생성된 음성이 여기에 표시됩니다" + CTA 버튼 1개
```

[문서] 추가 사항:
- Speed(0.7~1.2, 기본 1.0), Style exaggeration, Speaker Boost가 있다. 모델에 따라 노출이 다르다(v3·v4는 일부 없음).
- Clone Strength는 PVC와 v4 조합일 때만 나온다.
- 오디오 효과는 Filter, Noise, Space, Distance이고 종류마다 1회씩 추가한다. 미리듣기와 제거 버튼이 있다.
- 무료 재생성은 최대 2회다. 이때 버튼이 'Regenerate'로 바뀐다.
- 다화자를 쓰면 Dialogue 모드가 된다.
- **불일치**: 문서는 "웹에서는 언어를 지정할 수 없음"이라고 하지만, 앱에는 언어 드롭다운이 있다. 앱을 기준으로 삼는다.

확인 못 함 → 아래는 생성을 실행해야 볼 수 있다:
- 생성 중 상태
- 결과 플레이어
- 기록 항목의 구조
- 재생성 버튼 상태

### 2-2. 음성 생성 허브 `/app/create-voice` (유형 B) + 하위 4종

```
헤더: "음성 생성"  ·  우측 생성 한도 링 "0 / 3 생성됨"
├─ 카드: 즉시 음성 복제 — 설명, 길이 링(최소 10초 · 최고 3분), [새로 만들기]
├─ 카드: 프로페셔널 음성 복제 — 설명, 길이 링(최소 10분 · 최고 2시간), [🔒 생성하려면 업그레이드]
├─ 카드: 보이스 디자인 — 설명, 예시 프롬프트 칩 구름, [새로 만들기]
└─ 기타 도구: 음성 리믹싱 — 설명, [새로 만들기], 예시 프롬프트 미리보기
```

#### (a) 즉시 음성 복제 `/app/create-voice/instant`

- 브레드크럼: 음성 생성 › 즉시 음성 복제. 한도 링이 유지된다.
- 왼쪽(점선 드롭존): "오디오 파일을 업로드하거나 직접 녹음하세요" / "파일당 최대 10MB".
  - 하단 분할 버튼은 [파일 업로드] | [오디오 녹음]이다.
  - 숨은 file input이 있다.
- 오른쪽: 원형 진행 링(최소 10초 ~ 최고 3분)과 안내 문구 "3분 분량의 샘플을 제공하면 품질↑".
- 이후 단계 [문서]: 이름·라벨 입력 → 권리·동의 체크 → 저장 → '내 음성'에서 사용.

#### (b) 프로페셔널 음성 복제

- 현재 계정은 업그레이드가 필요해서 앱 화면을 확인하지 못했다.
- 흐름은 [문서] 기준으로 3장에 정리했다.

#### (c) 보이스 디자인 `?creationType=voiceDesign&action=create` (모달)

```
모달 헤더: 아이콘 + 제목, 닫기 X
├─ 프롬프트 라벨 + "모범 사례 ↗"
├─ 텍스트영역 (예시 프롬프트가 미리 채워짐)
├─ [셔플] + 예시 칩 가로 스크롤
├─ [음성 생성 ⊙비용 배지] 주 버튼   ← 누르지 않음
└─ [설정] 토글 → 모달 오른쪽으로 패널 확장
      ├─ 미리보기 텍스트 생성 토글(기본 켬)
      └─ 가이드 스케일 슬라이더(낮음 ↔ 높음)
```

[문서]:
- 결과는 후보 3개이고, 그중 하나를 골라 저장한다(보이스 슬롯 1개 사용).
- 비용은 미리보기 텍스트 글자 수만큼 든다.
- Loudness 컨트롤이 있다고 하지만 앱 모달에서는 보지 못했다.

#### (d) 음성 리믹싱 `?creationType=voiceRemix&action=create` (전체화면 오버레이)

```
닫기 X(우상단)
제목 + 한 줄 설명
컴포저 카드
├─ 상단 좌: [음성 참조 추가]   상단 우: [강도: 중간 ▾] [아이콘 버튼] [가이드]
│     강도 팝오버 = 설명 + 4단 세그먼트(현재 '중간')   [문서] Low/Medium/High/Max
├─ 프롬프트 입력 (영어 프롬프트 권장 안내가 플레이스홀더에)
└─ 하단 좌: [스크립트]   하단 우: "350 / 10,000 남음" + 전송 버튼(비활성)
빠른 시작: 음성+프롬프트 예시 카드 4개
```

"350 / 10,000"이 무엇을 세는 숫자인지(글자 수인지 비용인지) 확인하지 못했다.

### 2-3. 보이스 체인저 `/app/speech-synthesis/speech-to-speech` (유형 A)

```
가운데
├─ 점선 드롭존: 아이콘 + "클릭하여 업로드하거나 드래그 앤 드롭하세요"
│               + "각각 최대 50MB의 오디오 또는 비디오 파일" + "또는" + [오디오 녹음]
└─ 하단 액션 바(항상 보임): 남은 크레딧 · "0:00 총 지속 시간" · [다운로드] · [삭제] · [음성 생성](비활성)

오른쪽 패널 (설정 | 기록)
├─ 음성: "음성 자동 선택" ▸ (+추천)
├─ 모델: Eleven English v2 ▸
├─ 안정성 50% (더 다양한 ↔ 더 안정적인)
├─ 유사성 75% (낮음 ↔ 높음)
├─ 스타일 과장 0% (없음 ↔ 과장된)
├─ 출력 형식 드롭다운
├─ 화자 증폭 토글(켬)
└─ 배경 소음 제거 토글(끔)
```

- TTS와 같은 껍데기(유형 A)를 쓰고, 입력 영역만 '텍스트'에서 '오디오'로 바뀐다. **재사용 포인트**다.
- [문서]: 파일은 50MB 미만, 5분 이하다. 형식은 MP3, M4A, FLAC, OGA, OGG, WAV, MKV, WEBM, MP4, MOV다.

### 2-4. 더빙 `/app/dubbing` (유형 C)

```
제목 "더빙"
컴포저 카드
├─ 왼쪽 세로 소스 토글: [업로드] / [URL]
├─ 업로드 모드: [파일 선택] 아니면 여기에 끌어다 놓으세요
├─ URL 모드: URL 입력(예시 URL 플레이스홀더)
└─ 하단 칩 줄: [v2 모델] [언어 선택 ▾] [화자 유사도] ··· [전송](비활성)
     - 언어 선택: 검색 + 국기 + 언어명 목록(지역 변형 포함)
```

### 3-6. 우리 제품 녹음 UI 상태별 화면 정의 [제안] — 대표 추가 지시(프론트팀 요청) 반영

이 절은 ElevenLabs를 관찰한 기록이 아니라 **우리 설계안**이다. ElevenLabs에서 볼 수 없었던 상태(위 ❓)를 우리 기준으로 정의했다.

- 숫자 기준은 3-1(앱 확인)과 프론트 분석 `03-frontend-client-logic.md` 1-2, 1-3(문서 근거)을 따른다:
  - 합계 최소 10초, 최대 3분
  - 업로드 파일당 5초 이상, 10MB 이하
  - 녹음은 3:00에 자동 정지
- 문구는 우리 말투로 새로 쓴 예시이며, 2단계에서 다듬는다.
- 상태 기계는 프론트안(대기 → 권한 → 녹음 → 검토 → 업로드)과 같은 이름을 쓴다.

```
[S0 대기] ─녹음 누름→ [S1 권한 요청] ─허용→ [S2 녹음 중] ─정지/3:00→ [S4 검토] ─제출→ [S6 업로드 중] → 완료
    │                    └─거부/장치없음/http→ [S1x 권한 거부] ─파일 업로드로 전환→ S0
    └─파일 선택/드롭→ 검사 ─실패→ [S5 업로드 오류] (S6 실패도 여기로)
S4에서 합계 < 10초 또는 > 3:00 → [S3 길이 미달·초과] 배너가 S4 위에 겹쳐짐(별도 화면 아님)
```

공통 레이아웃: 왼쪽은 입력 영역(드롭존 ↔ 녹음 패널 ↔ 샘플 목록이 바뀜), 오른쪽은 총 길이 진행 링(10초 최소 눈금, 3분 최대), 하단은 액션 바(보조 액션 · 주 버튼).

| 상태 | 진입 조건 | 입력 영역(왼쪽) | 진행 링(오른쪽) | 주 버튼 / 보조 | 안내 문구 유형과 예시 | 이탈 경로 |
|---|---|---|---|---|---|---|
| **S0 대기** | 첫 진입, 샘플 0개 | 드롭존과 [파일 올리기] / [마이크로 녹음] 분할 버튼. 제약 한 줄 | 0:00, 10초 눈금 강조 | 다음(비활성) | 행동 유도: "파일을 끌어다 놓거나 바로 녹음하세요" / 제약: "파일당 10MB · 합계 10초~3분" / 품질 팁: "조용한 곳에서 1~2분이면 충분해요" | — |
| **S1 권한 요청** | 녹음 버튼을 처음 누름(권한이 `prompt` 상태) | 녹음 패널 자리에 **사전 안내 카드**: 마이크 아이콘, 이유 한 줄, [마이크 허용하기]. 이 버튼을 눌러야 브라우저 팝업이 뜬다. 팝업이 떠 있는 동안 "브라우저 창에서 '허용'을 눌러 주세요"와 대기 표시 | 변화 없음 | 마이크 허용하기 / 취소(S0) | 이유: "목소리 샘플을 녹음하려면 마이크가 필요해요. 녹음은 내가 정지할 때까지만 진행돼요" | 허용 → S2, 거부 → S1x |
| **S1x 권한 거부** | `NotAllowedError` / `NotFoundError` / https 아님 | 원인별 오류 카드(경고 아이콘 + 원인 + 해결 단계 + 대체 경로) | 변화 없음 | **파일 올리기로 전환**(주) / 다시 시도(보조) | 거부: "마이크 사용이 막혀 있어요. 주소창 왼쪽 자물쇠 → 마이크 → 허용 후 다시 시도하세요" / 장치 없음: "연결된 마이크를 찾지 못했어요" / 보안: "보안 연결(https)에서만 녹음할 수 있어요" | S0(파일 업로드), 재시도 → S1 |
| **S2 녹음 중** | 권한 허용 직후 자동 시작(3·2·1 카운트는 선택안) | 녹음 패널: 빨간 녹음 표시와 경과 타이머(0:00 / 3:00), **실시간 레벨미터와 파형**, 클리핑·무음 실시간 경고 칩 | 실시간으로 채워짐. 10초를 넘으면 최소 눈금 통과 표시 | **정지**(주, 스페이스바) / 취소(버리고 S0) | 상태: "녹음 중" / 실시간 경고: "소리가 너무 커요"(피크), "소리가 안 들려요"(5초 이상 무음) / 2:45부터 "15초 뒤 자동으로 멈춰요" | 정지 또는 3:00 자동 정지 → S4 |

#### 상태 공통 규칙

- **데이터 보존**: S5 네트워크 실패나 S2 중 탭 이탈 경고처럼 녹음본이 사라질 수 있는 순간에는 반드시 보존하거나 확인을 받는다(데이터 손실 방지).
- **접근성**:
  - 타이머와 상태 변화는 `aria-live="polite"`로 알린다.
  - 오류 문구는 `role="alert"`로 둔다.
  - 녹음과 정지는 키보드(스페이스바)로도 할 수 있어야 한다.
  - 레벨미터는 색만으로 구분하지 않고 텍스트 경고를 함께 낸다.
- **대체 경로**: 어떤 녹음 오류에서도 '파일 올리기'로 한 번에 넘어갈 수 있어야 한다.
- **시안 범위**: 이 표의 S0~S6 화면 시안과 파형·진행 링·레벨미터 컴포넌트 시안은 2단계에서 디자인팀이 만든다.

## 5. 우리 디자인 시스템 방향 — 1안

### 스타일 하나: **다크모드 UI**

`~/.claude/design-refs/ui-style-picker-ko.md` 그룹 B에서 골랐다. 근거:

1. 오디오 편집 도구(DAW)는 오래 쓰는 작업 화면이라 어두운 바탕이 관례다. 사용자 기대에 맞는다(업종 기대치 우선 규칙).
2. ElevenLabs는 밝은 미니멀 계열이다. 우리는 구조는 참고하되 생김새는 처음부터 다르게 가서 '베끼기' 위험을 줄인다.
3. 파형과 레벨미터 같은 오디오 시각화는 어두운 바탕에서 대비가 잘 산다.

라이트 테마는 토큰만 바꿔 쓰는 보조 테마로 두고, 1안의 기준은 다크로 한다.

### 구조 원칙 (관찰에서 뽑은 것, 생김새가 아니라 구조)

- **셸 하나와 화면 유형 5개(A~E)**로 모든 기능을 담는다. 새 기능은 유형 하나를 골라 끼운다.
- **입력 + 설정 패널 + 하단 액션 바** 3요소를 TTS, 보이스 체인저, 이후 효과음·음성 텍스트 변환이 같이 쓴다. 입력 슬롯만 텍스트, 오디오, 프롬프트로 바꾼다.
- **비용은 누르기 전에 보여 준다**: 주 버튼 옆에 예상 크레딧과 잔액을 둔다. 관찰된 패턴이고 신뢰와 과금 투명성에 필요하다.
- **설정은 접힌 상태에서도 요약값을 보인다**(예: '자동').
- **패널 안 드릴인**: 모델이나 음성처럼 선택지가 많으면 팝업 대신 패널 안에서 스택으로 처리한다.

### 우리 쪽 개선 제안 (관찰 사실이 아닌 제안)

- **녹음 패널을 하나의 컴포넌트로 만든다**:
  - 녹음 전 '환경 점검'(입력 레벨, 소음)을 둔다.
  - 녹음 중에는 레벨미터와 목표 길이 진행 링을 보여 준다.
  - 검토 때는 파형, 구간 삭제, 재녹음을 지원한다.
  - IVC, PVC, 보이스 체인저가 같이 쓴다.
- **상태를 문서로 정의한다**: 모든 입력 컴포넌트는 기본, 포커스, 드래그 오버, 처리 중, 오류, 완료, 잠김(요금제)의 7상태를 정의한 뒤 만든다.
- **한국어 우선 문구 체계**: 안내 문구를 '행동 유도, 제약, 품질 팁, 할당량, 잠금, 비용' 6종 템플릿으로 나눠 우리 말투로 새로 쓴다.

## 6. 다른 팀에 필요한 것 / 주의

- **기획팀(01)**: 2장의 화면 유형(A~E) 분류를 기능 지도의 화면 단위와 맞춰야 한다.
- **프론트(03)**: 녹음 상태표(3장)의 ❓ 칸은 프론트 쪽 MediaRecorder 상태 설계와 같이 채운다.

- **대표**: 3-5의 '실행 확인 필요' 항목을 볼지 결정해 주길 바란다. 크레딧 차감과 녹음이 포함된다.
- **표절 방지**: 이 문서의 UI 문구, 예시 프롬프트, 이름은 관찰 기록이다. 우리 제품에는 새로 쓴다. 그래픽(구체형 오브, 그라데이션 카드 등)도 쓰지 않는다.
