## 1. 요약 (대표용)

1. 앱은 3개 플랫폼(ElevenCreative 웹앱 / ElevenAgents / ElevenAPI)을 왼쪽 아래 전환기로 오간다. 지시서의 메뉴 22개를 모두 열어 봤고, '더 많은 도구' 안의 4개(템플릿·오디오 네이티브·프로덕션·Ads 엔진)까지 확인했다. [앱]
2. 모든 생성 기능은 **크레딧 한 통장**에서 빠진다(TTS 1자=1크레딧, 체인저 1분=1,000 등). 클로닝만 크레딧이 아니라 **음성 슬롯 수와 월 음성 작업 횟수**로 묶는다. [문서·데이터팀 07 §3]
3. 클로닝은 두 갈래다. **즉시 복제(IVC)**: 학습 없이 10초~3분 샘플로 곧바로 만든다(앱 화면 기준 파일당 10MB, 업로드 또는 녹음, 권리·동의 체크). **프로페셔널 복제(PVC)**: 30분~3시간 샘플로 전용 모델을 학습한다. 본인 목소리만 가능하고 낭독 캡차로 본인 확인을 하며, 학습 대기는 3~6시간(최대 24시간)이다. IVC는 Starter부터, PVC는 Creator부터 쓸 수 있다. [앱·문서]
4. MVP는 대표 결정(국내 우선, 안 B 원화 종량 한국어 음성 API로 진입, 안 A 동의 검증을 차별점으로)에 맞춰 짰다. **P0 = TTS·STT API + 한국어 음성·발음 사전 + 원화 종량 계량·콘솔 + 웹 체험 화면 + 생성 로그·AI 고지**. **P1 = 동의 검증을 붙인 즉시 복제, 실시간(스트리밍) TTS/STT, 음성 에이전트 기본, 보이스 디자인**. 나머지 크리에이티브 기능(뮤직·비디오·더빙·스튜디오 등)은 P2다(§5).
5. 물량 가정(출시 후 3개월, 월)은 **안 B 기준으로 다시 산정했다**(§6-0, 2026-11-22). 마케팅팀 B2B 고객당 물량을 썼다.
   - 기본안(AICC 중소 3·중견 1, 콘텐츠 12곳): 에이전트 15.6만 분, STT 1.47만 시간(녹취 전량 상한), TTS 2,146만 자, 피크 동시 통화 29
   - 모두 추정이고 고객 수는 가정이다.
   - 소비자형 1차안(MAU 5,000 [가정], STT 144시간)은 참고로만 남겼다.

## 3. 음성 녹음·클로닝 흐름 (상세)

### 3-1. 진입 구조 [앱]
- `/app/create-voice` 화면 상단에 **"0 / 3 생성됨"** 카운터가 있다(Free 계정의 커스텀 음성 슬롯 3과 같은 값). 카드 4개: 즉시 음성 복제(새로 만들기), 프로페셔널 음성 복제("생성하려면 업그레이드"), 보이스 디자인(새로 만들기), 기타 도구 > 음성 리믹싱.
- 문서상 진입은 보이스 라이브러리 옆 '+'(음성 만들기) 버튼에서도 된다. [문서 D eleven-creative/voices/voice-cloning/instant-voice-cloning.md]
- 진입 버튼 이름은 사이드바 '음성 만들기'다(read_page로 확인). [앱]

### 3-2. 즉시 복제(IVC) vs 프로페셔널 복제(PVC) 한눈 비교

| 항목 | 즉시 복제 (IVC) | 프로페셔널 복제 (PVC) | 출처 |
|---|---|---|---|
| 원리 | 학습 없음. 기존 모델이 샘플로 음색을 추정 | 샘플로 **전용 모델 파인튜닝** | [문서] |
| 샘플 길이(앱 표시) | 최소 10초 · 최고 3분 | 최소 10분 · 최고 2시간, 30분 이상 권장 | [앱] |
| 샘플 길이(문서 권장) | 1~2분(일부 문서 1~3분). 3분 넘으면 효과 거의 없고 오히려 불안정 | 최소 30분, 최적 2~3시간. 업로드 후 피드백은 "1시간 이상, 3시간 가까이" 권장 | [문서] |
| 최소 조건 | 파일당 5초 이상, 합계 10초 이상 | 문서에 없음 | [문서 help-center what-files-do-you-accept] |
| 파일 | 파일당 최대 10MB [앱]. 파일 수 상한은 확인 못 함 | 크기·개수 상한 문서에 없음. 여러 시간이면 약 30분 단위로 나눠 올리기 권장 | [앱·문서] |
| 형식 | MP3 192kbps 이상 권장(IVC 가이드는 128kbps 이상). WAV는 이점 없고 업로드 문제 가능 | 같음. 녹음 시 WAV 44.1/48kHz 24bit 권장 | [문서] |
| 입력 방식 | 파일 업로드 / 오디오 녹음(브라우저 마이크) | 샘플 업로드 / 직접 녹음(서술·대화·광고용 예시 대본 제공, 내 대본 업로드 가능) | [앱·문서] |
| 전처리 | API에 `remove_background_noise` 옵션(샘플 소음 제거, 소음 없으면 품질 저하 가능). 웹 화면 옵션은 확인 못 함 | 클립별 '오디오 설정'에서 소음 제거·**화자 분리** | [문서 API·가이드] |
| 메타데이터 | 이름(필수), 라벨(언어·억양·성별·나이), 설명 | 이름, **샘플 언어(필수)**, 라벨, 설명 | [문서 API ivc/create, pvc/create] |
| 권리·동의 | "복제할 권리와 동의가 있다" 확인 후 저장 | **본인 목소리만**(동의가 있어도 타인 불가). 낭독 캡차로 본인 확인 | [문서] |

### 3-5. 우리 제품 설계 시사점 (기획팀 판단)
- **동의 검증(안 A)은 IVC부터 넣는다.** ElevenLabs의 IVC는 체크박스 동의와 보호 음성 대조뿐이다. 낭독 캡차는 PVC에만 있다. 마케팅팀 통제 장치(08 문서 §3-4: 즉석 문장 낭독, 동의서·증빙 보관, 유명인 차단 목록)를 **IVC 생성 단계에 필수로** 넣는 것이 차별점이 된다.
- 녹음 UX는 "누적 길이 링 + 권장 길이 안내 + 파일·녹음 병행"을 기본으로 한다. 녹음 이후 화면(재녹음, 구간 삭제, 레벨 미터 유무)은 **실행 확인 필요**다.
- 클로닝 한도는 크레딧이 아니라 **슬롯 수 + 월 작업 횟수**로 잡는 구조가 단순하다(남용 방지 효과도 있음).
- PVC는 학습 파이프라인(대기열, 상태 머신, 재시도, 모델별 학습)이 필요해 개발 부담이 크다. 그래서 P2로 둔다(§5).

**피크 동시 통화 계산** (DevOps 요청, GPU 대수 입력값)
- ElevenLabs 동시 처리 추정 방식을 그대로 썼다(D overview/administration/workspaces/concurrency-estimator.md).
  - 평균 동시 수 = 활동 분당 유입 × 평균 길이 × 여유 계수
  - 피크 = 평균 + z × √평균
- 대입한 값
  - 활동 시간: 영업일 21일 × 8시간 = 월 10,080분 [가정, 콜센터 운영 시간 근거 없음]
  - 여유 계수 1.2, z = 2.33(99%)
- 평균 동시 수 = 에이전트 분 ÷ 10,080 × 1.2
  - 3개월 기본: 18.6 → 피크 29
- 시간대별 몰림(점심·월요일 오전)은 반영하지 않았다. 실제 피크는 더 클 수 있다. AICC 인터뷰에서 시간대별 콜 분포를 받아 고쳐야 한다.

**1차안(§6-1~6-4, 소비자형)과 비교**
- 3개월 기본 기준으로 STT는 144시간 → **14,651시간**(약 100배)이다. 녹취 전량 STT라는 상한 가정 때문이다.
- 에이전트는 0 → **156,000분**이다. 실시간 물량이 새로 생겼다.
- TTS는 1,712만 → 2,146만 자로 비슷한 규모다.
- **DevOps 비용표의 STT(현재 144시간)와 실시간 가정을 이 표로 다시 맞춰야 한다**(§8).
- 클로닝(IVC) 물량은 마케팅 추정에 없다. B2B에서 클로닝 수요는 추정하지 않았으므로 §6-4 값을 참고로 유지한다. 확인 못 함이다.

**교차 검산·손익 (데이터팀, 2026-11-22)**
- 데이터팀이 위 피크 동시 통화로 에이전트 GPU 대수를 따로 계산했다. 결과는 3개월 1/1/1장, 12개월 1/2/3장으로 같았다(발화 비중 50% × RTF 0.1228 ÷ GPU 1장당 3.5).
- 손익 정본은 07 §9-5다. B2B 기본안은 3개월부터 흑자(월 +810만~+1,186만 원)이고, 3개월 보수안만 적자다.
- DevOps도 이 표로 비용표를 다시 맞췄다(06 §4.9). 3개월 기본은 실시간 GPU 3장(예비 포함)과 배치 1장이다.
  - 고정비: 한국 약 $15.1k / 혼합 약 $12.3k / 해외 약 $3.7k
  - 변동비: 약 $1.3k + LLM
- **확인 필요(대표 조율)**: 3개월 기본 실시간 GPU가 데이터팀은 1장, DevOps는 3장(예비 포함)이다. 예비분과 계산 기준 차이인지 두 팀이 맞춰야 손익(07 §9-5)과 비용(06 §4.9)이 같은 전제가 된다.
  - 원인 확인(DevOps, 2026-11-22): 두 팀의 평균 부하는 같다. 차이는 두 가지다.
    - ① 99% 피크 여유: 이항분포 99% 분위로 동시 5 → 2장
    - ② 예비 1장
  - 06 §4.9에 A(1장) / B(2장) / C(3장) 비교표가 있다. **SLA 결정은 대표 몫이다.** 결정 전까지 데이터팀은 A와 C를 함께 보여 준다.
- 후속: AICC 인터뷰에서 시간대별 콜 분포가 오면 기획팀이 피크를 다시 계산한다. 그 값은 DevOps(실시간 GPU 대수, 피크 29 → 55면 3장 → 4장)와 데이터팀에 바로 전달한다.

### 6-5. 주의
1. **안 B는 종량제라 이 구조(요금제 한도 × 소진율)가 실제와 다를 수 있다.** API 고객은 한도가 아니라 자기 서비스 트래픽만큼 쓴다. AICC 인터뷰(마케팅 다음 과제)가 끝나면 "API 고객 수 × 고객당 월 물량"으로 다시 산정해야 한다(§8 요청).
   - 진행(2026-11-21 대표 조율): 마케팅팀이 B2B 고객 유형별 1곳당 월 물량을 추정한다. 결과가 나오면 기획팀이 이 절을 다시 산정하고, 데이터팀이 손익분기(07 §9)를 갱신한다.
   - 재산정 구조는 데이터팀 07 §9-4를 따른다. 매출 = API 고객 수 × 고객당 월 물량(TTS 자, STT 시간, 통화 분)이고, 동시 통화 수는 고정비(GPU 대수) 입력이다.
   - 단가안은 07 §9-1이다(TTS 1천 자당 100원/50원, STT 분당 4.5원, 에이전트 분당 75원, [제안]).
   - 클로닝 건수(§6-4)는 데이터팀이 검산했다. 한도에 걸리지 않고, 크레딧 밖이라 매출은 0이다.
2. 한국어 TTS 1분당 글자 수는 확인 못 함이다(영어 기준 1분 ≈ 1,000자). 분 단위로 환산하려면 실측해야 한다(실행 확인 필요).
3. 무료 사용자가 크레딧 소비의 40~59%를 차지한다. 무료 한도 설계가 원가를 크게 좌우한다(데이터팀 해석).
4. 데이터팀 지적: 기본안 STT 144시간은 DevOps 비용표 가정(배치 500시간 + 실시간 200시간)보다 훨씬 작다. 단 에이전트 통화 분은 이 표에 없다. 에이전트를 P1로 열면 실시간 STT·TTS 물량이 따로 생긴다.
   - 반영(2026-11-21): DevOps가 비용표 STT를 기본안 월 144시간으로 맞췄다(06 §4.1). 에이전트·실시간 STT·TTS는 P1 별도 추가분(06 §4.5)으로 분리했다.
   - DevOps 요청: 안 B로 재산정할 때 **피크 동시 통화 수**도 함께 낸다. GPU 대수를 정하는 입력값이다.

## A-2. 보이스 라이브러리 (음성 > Explore) + My Voices

- 하는 일: 커뮤니티가 Professional Voice Clone(PVC)을 공유하고 사용 시 보상을 받는 마켓플레이스. 공유 가능한 것은 PVC뿐(IVC, Voice Design 보이스는 공유 불가). 접근: 사이드바 Voices > Explore. 출처: D eleven-creative/voices/voice-library.md
- 사용자 흐름(탐색/사용):
  1. Voices > Explore 진입. Handpicked Collections(용도·장르·언어별 큐레이션, 정기 갱신) 또는 검색/필터.
  2. 검색: 이름, 키워드, voice ID, 또는 오디오 파일 업로드/드래그앤드롭(원 보이스 및 유사 보이스 검색. 음성만 있는 파일 권장, 배경음/노이즈 있으면 Voice Isolator로 정리, 긴 클립 불필요)(비디오 파일도 가능).
  3. 보이스 클릭으로 샘플 재생(다국어 프리뷰는 하단 플레이어에서 언어 선택).
  4. "Use voice" 버튼 → TTS가 해당 보이스 선택된 채로 열림. 사용 시 notice period가 계정에 저장됨(이후 라이브러리에서 내려가도 notice period 동안 계속 사용 가능).
  5. (선택) "+" 버튼으로 My Voices에 저장. 모든 보이스 선택 메뉴에 노출. My Voices에서 "T" 버튼으로 해당 보이스로 TTS 열기.
- 입력·설정 항목(정렬/필터):
  - 정렬: Trending(인기순), Latest, Most users, Character usage
  - 필터: Language(해당 언어로 학습된 보이스; 모든 보이스는 지원 언어 어디에나 쓸 수 있으나 태그된 언어에서 최상), Accent(언어 선택 시 활성), Category(Conversational, Narration, Characters, Social Media, Educational, Advertisement, Entertainment), Gender(Male, Female, Neutral), Age(Young, Middle Aged, Old), Notice period(최대 2년), Live Moderation enabled(제외 가능), Quality(Any / Studio Quality: 적절한 장비로 녹음·믹스되고 리버브/왜곡 등 결함 없음, QA 검수), "custom rate가 있는 보이스 제외" 필터(FAQ)
  - My Voices 표시 정보: 학습 언어, 카테고리, notice period 길이. 아이콘: 노란 체크=PVC, 검정 체크=Studio Quality PVC, 번개=IVC, 아이콘 없음=Voice Design 보이스
  - More actions(점 3개): Copy voice ID / Edit voice(이름·설명 변경, 본인에게만 보임) / Share voice(링크 생성, 링크 사용자의 My Voices에 추가됨) / View history(해당 보이스 TTS 생성 이력) / Delete voice(영구, 확인 필요) / Add to collection
  - Collections: My voices > Collections > Create collection(이름 + 아이콘 선택). Shift+Click 다중 선택, 컬렉션으로 드래그, 휴지통 아이콘으로 드래그해 삭제.
- 한도/규칙:
  - 라이브러리에서 저장한 보이스는 커스텀 보이스 슬롯을 사용하지 않음. 슬롯은 Voice Design / Voice Cloning으로 만든 보이스에만 소진.
  - notice period: 최소 30일, 최대 2년(help FAQ). notice 없으면 소유자가 공유 중단 시 즉시 사용 불가. notice 있으면 이메일+앱 알림, API에서는 Get Voice 응답의 `disable_at_unix`(없거나 null이면 미활성), 웹훅(설정 페이지 https://elevenlabs.io/app/settings/webhooks)으로 보이스 제거 알림 가능. notice 기간 중 삭제된 보이스는 다시 저장 불가. 공유 재개 시 notice period 리셋. 소유자는 notice를 길게 잡으면 보상 증가.
  - Live Moderation: 켜진 보이스로 생성 시 금지 카테고리 텍스트 검사 → 지연 시간 증가 가능.
- 요금제 제한:
  - 라이브러리 보이스는 무료 티어에 API로 제공되지 않음(경고문). 출처: voice-library.md, quickstart.md
  - 일부 보이스는 유료 구독 전용(소유자가 제한했거나 credit multiplier 존재) → 무료 사용자는 "This voice is not available for free users." 메시지. credit multiplier 예: 2x면 일반 보이스의 2배 크레딧. custom rate는 레거시이며 신규 공유 보이스에는 더 이상 불가. 배수는 보이스 소유자가 정한 rate + 사용자의 구독 플랜에 따라 결정. 
  - 소유자가 "Exclude free users" 옵션으로 신규 무료 사용자 추가 차단 가능(기존 추가자는 영향 없음, 사용량·트렌딩 노출 감소 가능).
- 공유(퍼블리시) 흐름 (PVC 한정):
  1. My Voices → 보이스의 More actions → "Publish to Library"(PVC는 My Voices 상단에도 강조).
  2. 팝업에서 "Publish to the Voice Library" 토글 ON.
  3. notice period, Live Moderation 설정(Voice Library Addendum 참조).
  4. 이름·설명 입력. 이름 규칙: "이름 + 핵심 음성 특성 또는 페르소나(하이픈 -로 구분)", 40자 이하; 금지: 공인/기업/밴드/인플루언서 이름, SNS 핸들, 전체 대문자 단어, 이모지·비문자, 노골적·유해 단어, 단어 "voice". 예시: "Serena - Calm, Friendly, Warm". 설명: 구체적 용도·톤·스타일·감정·속도, 무관한 용도 나열 금지(오해·스팸 설명은 비승인).
  5. 라벨 설정: language, accent, gender, age, use case, tone, style.
  6. Voice Library Addendum 동의 및 동의·확인 항목 제공(legal@elevenlabs.io 문의 안내).
  7. 팀 검수. 사소한 수정은 팀이 대신 할 수 있음. 반려 가능. 반복 위반 시 업로드/공유 제한. 검수 소요시간 추정치 없음(대기열 의존).
  - 커스텀 보이스 프리뷰: My Voices → More actions → Edit in Library → Manage your voice → Custom voice preview 드롭다운에서 선택. 대상은 **70–150자** 텍스트로 생성한 오디오(모든 모델, v3 포함).
  - 비공개 공유: More actions → Share Voice. 워크스페이스 멤버/그룹 추가. PVC는 "Anyone with the link" 토글로 외부 공유(링크로 누구나 계정에 추가). IVC와 Voice Design 보이스는 워크스페이스 내부에서만 공유 가능.
  - 공유 해제/삭제: Edit in Library → 토글 해제 → (notice period 없었다면) Delete voice 가능. notice period 있었다면 만료 후 삭제. notice 기간 중에는 이미 저장한 사용자만 사용, 라이브러리에는 비노출.
- 금지: AI 생성/AI 향상 보이스, IVC, Voice Design 보이스는 라이브러리 공유 불가(위반 시 공유 금지·계정 정지 가능). 음성 인증(CAPTCHA) 회피 등은 Prohibited Use Policy 위반으로 영구 정지 가능. 어린이/어린이처럼 들리는 보이스(성인이 모사한 경우 포함)는 라이브러리 추가 불가.
- 기타 FAQ: 소셜에서 인기 있는 보이스 예시 = 남성 Brian, Liam, Adam / 여성 Jessica, Matilda, Sarah.
- 출처: D eleven-creative/voices/voice-library.md, D eleven-creative/quickstart.md

### 2-1. Payouts (보이스 공유 수익)

## A-3. 스튜디오 (ElevenCreative Studio 4.0)

- 하는 일: 프롬프트 우선 방식의 영상·오디오 프로젝트 제작 도구. 설명을 입력하면 Studio Agent가 초안 생성. 비디오 프로젝트는 재사용 자산 Library + 멀티트랙 타임라인(+Script, Captions 패널), 오디오 프로젝트는 장문 내레이션/팟캐스트/오디오북용(챕터·문단 단위). 팀 공유·코멘트 가능.
- 사용자 흐름:
  1. 상단 "What would you like to create?" 프롬프트 바에 설명 입력 / Inspiration 카드 선택 / Upload(텍스트·오디오 파일은 오디오 레이아웃, 비디오 파일은 비디오 레이아웃+자막 가능) / "+ New blank project" (유형: Video project (New), Audio project, Video project(구버전))
  2. 설정 대화상자에서 프로젝트 설정 후 Create
  3. 타임라인 에디터에서 영상·내레이션·음악·효과음 추가
  4. Share로 팀 공유·피드백 수집
  5. Export로 오디오/비디오 렌더 (수정 후 다시 Export하면 새 버전 생성)
  - 비디오 보이스오버 만들기(FAQ): Studio 홈에서 새 비디오 프로젝트 → Library "Create +" → Upload(기존 영상) 또는 Video(생성) → Speech로 보이스오버 생성 → 타임라인에 드래그해 정렬 → Script 패널에서 대본/보이스/모델 변경(재생성 필요) → Captions 패널에서 보이스오버 트랙을 자막 소스로 선택 → Export.
- 입력·설정 항목:
  - 기본 모델: 대부분의 새 프로젝트는 Eleven Multilingual v2. Project settings에서 Eleven v3/v4 등 변경 가능(언제든).
  - Inspirations(예시 템플릿): Film trailer(Video), Explainer video(Video), Product video(Video), Audio documentary(Video/Audio), How to tutorial(Video), Audio podcast(Audio), Captions(Video); "View all Inspirations"에서 카테고리별 검색.
  - Studio Agent (비디오 프로젝트 내 AI 공동편집자): 영상 길이·톤·구조·전환을 물은 뒤 타임라인 초안 생성(클립, 보이스오버, 보이스, 효과음, 자막). 기능: 클립 분석(프레임 단위 맵, 예: "로고 나올 때 swoosh 추가"), 채팅 내 에셋 탐색(보이스/효과음 검색·미리듣기·배치), 모델 선택·확인(이미지 모델 5개, 비디오 모델 5개 중 요청에 맞게 선택, 확인 시 변경 가능). 모드 토글: Create 모드(타임라인 편집·클립 삽입·미디어 생성·텍스트 오버레이·오디오 조정) / Plan 모드(타임라인 변경 없이 계획만: 푸티지 분석·음성 전사, 에셋/보이스 검색, 스크립트·씬 계획, 타임라인 편집 계획과 gap 관리 계산, TikTok/YouTube/Instagram 가이드). 수동 편집 병행 가능.
  - 오디오 프로젝트 사이드바: Playback controls, Type, Model, Voice, Override settings, Generation history. AI Tools: Enhance text(전달 가이드용 텍스트 다듬기), Remove background audio(Voice Isolator 사용), Use voice changer, Direct speech with your voice(Actor Mode: 참조 녹음/업로드로 전달 방식 지정, 억양까지 복제, 생성 전 크레딧 표시).
  - 타임라인/트랙: 챕터 전체 뷰, 문단·문장 사이 타이밍 조정, trim/split/duplicate, 줌·팬, 파형. 음악(프롬프트로 생성 또는 가져오기, trim/duplicate/move/볼륨, 스테레오 유지), 효과음(텍스트 프롬프트로 생성 또는 SFX library에서 선택, 미리듣기 재생성 후 적용, 레이어링). 경고: 효과음은 ElevenReader 내보내기와 Studio API 스트리밍에서 지원 안 됨.
  - 챕터: 오디오 프로젝트에서 Chapters 사이드바. 문서 가져오면 챕터 자동 감지, "+"로 추가, Chapter actions로 이름 변경/삭제, 드래그 정렬.
  - Generate/Regenerate/Play: 문단 상태 막대(미변환=연한 회색, 변환됨=진한 회색; 다크모드는 흰색). Play 모드 2가지: "Until end (generate clips ahead)", "Until end (generate one at a time)". 기존 오디오/비디오 재생은 크레딧 무소모.
  - Insert break: 기본 1초, 최대 3초. 일부 신모델은 break 태그를 줄이거나 무시. 다른 트랙에는 영향 없음.
  - Lock paragraph: 잠금 시 재생성·보이스/설정 변경·생성 이력 접근 불가, 생성된 뒤에만 사용 가능, 내레이션에만 적용.
  - Generation history: 문단별 이전 생성 청취/다운로드/복원(Restore generation)/삭제(영구). 가져온 미디어·비디오 클립은 이력 없음.
  - Undo/Redo, 키보드 단축키(Project options > Keyboard shortcuts; 전체 보이스 색 오브 표시는 Ctrl+Alt+A / Cmd+Opt+A).
  - Files: 드래그앤드롭/Upload file/Record로 오디오 업로드, "This project"/"Workspace" 토글. 업로드한 오디오는 배포 플랫폼에 게시 불가.
  - 비디오 Library(Project/Workspace 탭, Origin·Status·Timeline presence 필터) "Create +": Video, Lip sync(아바타를 음성 클립에 동기화), Image, Speech, SFX, Music, Upload / Elements: Text(오버레이). 비디오 생성 컨텍스트: Image refs, Reference videos, Start frame, End frame.
  - Script 패널: Voiceover(문단별 보이스·모델), Pronunciations(Pronunciations Editor: alias/phoneme 규칙).
  - Captions 패널: 오디오 트랙을 소스로 선택, Transcript 탭(타임스탬프 텍스트 Edit), Style 탭(글꼴·색·크기·위치, 내보낸 비디오에 burn-in).
  - 화면비: 16:9(YouTube 광고/와이드), 9:16(TikTok/Reels/Shorts), 4:5(LinkedIn/Facebook 광고), 1:1(Instagram).
  - 보이스: IVC, PVC, Voice Library 보이스, Voice Design 합성 보이스 사용 가능. 한 문단에 여러 보이스 할당 가능(색 구분). "Replace voice across project"로 전체 교체(영향 문단 수 표시, "Replace and clear impacted audio").
  - 보이스 설정: Override settings(선택 텍스트만) / 미오버라이드 시 프로젝트 내 해당 보이스 전체에 적용(재생성 필요). Alias(프로젝트 내 별칭), Volume(기본 0.00 dB, 최소 -30 dB ~ 최대 +5 dB), Speed(기본 1.0, 최소 0.7 ~ 최대 1.2), Stability(권장 시작값 약 50), Similarity(약 75), Style exaggeration(일부 모델만, 0 권장, 지연 증가), Speaker boost(지연 약간 증가). 비결정적이라 슬라이더는 랜덤 범위 폭을 정함.
  - 발음 사전: lexicon/dictionary 파일 업로드(phoneme 태그 또는 alias 태그). Phoneme 태그는 "Eleven Flash v2" 모델에서만 호환. 사전은 처음부터 끝까지 검사하고 첫 번째 치환만 적용. Pronunciations Editor에서 기존 사전 Connect, 새 규칙/사전 생성.
  - Export settings(Project settings > Export): 메타데이터 Title, Author, ISBN, Description(다운로드 오디오에 자동 삽입), 이전 버전 접근, 볼륨 정규화.
  - Export 옵션: 단일 챕터는 MP3 또는 WAV, 비디오 트랙/자막이 있으면 비디오도 가능. 멀티 챕터는 챕터별 또는 전체(단일 파일 또는 챕터별 ZIP). 비디오는 자막 켜고 비디오 트랙(또는 shareable TTS video) 추가 필요, 선택한 caption template로 렌더. shareable TTS 비디오는 링크 복사 가능. 이전 Export 접근: Project options > Exports(또는 Export > History 탭).
  - 배포 내보내기: Export > Publish > InAudio(LPF 형식 생성, 무료 미리듣기 챕터 선택=해당 챕터 첫 5분, 내레이터 표기 기본 "Digital Voice" + 보이스명) / Spotify(MP3 형식, 동일한 미리듣기 5분 선택, Spotify for Authors에서 New Audiobook 업로드). 프로젝트에 IVC가 있으면 내보내기 전에 보이스 인증(Verify → Voices > My Voices → "Click to verify") 필수. 디지털 보이스 내레이션임이 메타데이터/설명에 표기됨. InAudio는 Barnes and Noble, Rakuten, Everand, Scribd 등으로 유통.
  - 공유/코멘트: 읽기전용 링크(언제든 취소 가능), 코멘트는 플레이헤드 타임스탬프에 고정, 계정 없는 사용자도 이름 입력 또는 익명 가능, 스레드 답글·멘션·이메일 알림, Resolved 처리 시 알림 중지(재오픈 가능).
  - 가져오기 파일 형식: EPUB(최선; 챕터 제목을 'Heading 1'로 포맷하면 챕터 자동 분리), PDF, DOCX, TXT, HTML, URL.
- 한도:
  - 프로젝트당 최대 500 챕터, 챕터당 최대 400 문단, 문단당 최대 5,000자.
  - 플랜별 최대 프로젝트 수: Free 500 / Starter 750 / Creator 1,000 / Pro 3,000 / Scale 20,000 / Business 20,000 / Enterprise 무제한. 한도 초과 상태로 다운그레이드해도 기존 프로젝트 접근 유지, 신규 생성만 불가.
  - 무료 재생성 2회(텍스트/보이스/설정 변경 없을 때). 버튼이 "Regenerate"면 무료, "Generate"면 과금.
  - 대량 변환 Auto-regeneration(Export로 챕터/프로젝트 전체 변환 시 자동): 볼륨 왜곡, 음성 유사도, 오발음, 누락/추가 단어 검사 → 문제 시 최대 2회 무료 자동 재생성(처리시간 증가 가능).
  - Studio Agent 파일 크기 추가 제한 없음. 웹앱 전용, API 미제공. EU/인도/싱가포르 데이터 레지던시 격리 환경에서는 Studio Agent 불가(Studio 자체는 가능).
- 요금제/크레딧:
  - Studio는 모든 플랜(무료 포함) 사용 가능. 단 "Create a podcast (GenFM)" 기능은 유료 구독 필요.
  - 출력 품질(플랜별 자동, 크레딧 소비에는 영향 없음): Free/Starter/Creator = 128 kbps MP3(또는 128 kbps 소스에서 변환한 WAV); Pro/Scale/Business/Enterprise = 16-bit 44.1 kHz WAV 또는 192 kbps MP3(Ultra Lossless). 기존 프로젝트는 생성 시 설정이 고정(Export 메뉴 Format에 호버해 확인).
  - 무료 플랜 비디오 내보내기에 워터마크, 유료는 없음.
  - 크레딧: 오디오 생성 시 소모. 전부 생성된 프로젝트의 Export는 추가 비용 없음, 미변환 문단이 있으면 Export 전 필요 크레딧 표시. 편집된 문단만 재과금.
  - Studio Agent: 모든 플랜. 채팅은 토큰 5종(input, output, thinking, cache read, cache write) 기준 크레딧 소모. 음성·이미지·음악·효과음·비디오 생성은 해당 기능 표준 요율. 엔터프라이즈는 fiat 과금 가능.
  - 다운그레이드/해지 시: IVC·PVC로 오디오 생성 불가, 일부 Voice Library 보이스(custom rate 포함) 접근 상실. 데이터는 삭제하지 않음(문서 작성 시점 기준).

## A-4. 흐름 (Flows) + 템플릿 (Templates)

### 4-1. Flows
- 하는 일: 무한 캔버스의 노드 기반 비주얼 워크스페이스로 이미지·비디오·음성·음악·효과음 파이프라인을 구성. 현재 **Alpha**(기능 변경 가능). 50+ 이미지/비디오 모델 + ElevenLabs 음성·음악·효과음 모델 체인. 특정 노드만 재실행하는 비파괴 반복.
- 사용자 흐름:
  1. 대시보드 "+ New Flow" → 빈 캔버스 (또는 에이전트에게 설명 / Inspiration에서 시작 / Templates 실행)
  2. 캔버스 우클릭 또는 하단 툴바 "+"로 노드 추가
  3. 출력 포트에서 다른 노드 입력 포트로 드래그해 연결(드래그 시 호환 다음 노드 자동 제안 = Contextual navigation)
  4. 각 노드 Run 버튼으로 생성; 단일 노드 재실행 가능(그 경로의 하위 노드만 갱신)
  5. 에셋 다운로드 / Studio로 내보내기 / 템플릿으로 게시해 API 실행
- 입력·설정 항목(노드 종류):
  - 이미지: Image generation(50+ 모델), Edit image, Image upscale, Remove background
  - 비디오: Video generation(이미지→영상/텍스트→영상), Edit video, Video upscale, Lip syncing(음성 노드+비디오/이미지로 말하는 헤드), Dubbing, Composition(오디오/비디오 레이어 최종 프리뷰 노드)
  - 오디오: Text to Speech(Eleven v4 포함), Sound Effects, Music generation, Voice Changer, Voice Isolator, Audio Effects(Filter, Noise, Space(룸 리버브), Distance(화자 원근) 중 하나 이상)
  - 텍스트/기타: Text, LLM(스크립트 작성·프롬프트 확장), Upload media, Avatar(말하는 아바타 영상), Speech to Text
  - Flows Agent: 에이전트 채팅에 설명 입력(파일 업로드 가능) → 질문 후 노드를 캔버스에 배치. 기존 플로우도 분석·수정 가능. 권한 3가지: Approve each(모든 동작 확인) / Auto-run(자동 실행) / Auto under threshold(단일 동작 비용이 지정 임계값 초과할 때만 확인). 수동 편집과 병행.
  - 협업: 실시간 커서·동기화·공동 실행·노드 코멘트. Basic Seat 멤버(전체 시트 없이 열람/실행 관전/출력 검토/코멘트), 공개 플로우는 외부 익명 참여자 열람. 워크스페이스에 공유하면 협업자 목록에 자동 표시(별도 링크 불필요). 협업 자체는 크레딧 비소모.
  - 내보내기: 개별 에셋/최종 컴포지션 다운로드, Studio로 전송(Files 라이브러리에 저장 후 가져오기), 템플릿 게시 후 API.
- 한도: 문서에 수치 한도 없음("50+ 모델"만 명시). 노드 실패 시 해당 노드만 영향, **실패 실행은 과금 안 됨**.
- 요금제/크레딧: 노드 생성마다 모델·설정에 따라 크레딧(단독 도구와 동일). 재실행 = 새 생성·새 과금. Run 버튼 호버 시 크레딧 표시. Flows Agent는 전 플랜 가능, 채팅은 처리 토큰량/종류에 따라 과금(고정 요금 없음), 생성물은 표준 요율. 상업 권리는 구독 플랜 기준.
- API: 앱에서 만든 플로우를 템플릿으로 게시 후 API로 실행 / 코드로 체인 구성(Image & Video API는 호출 1회=노드 1개 개념, 이전 생성물을 레퍼런스로 사용).
- 출처: D eleven-creative/products/flows.md

### 4-2. Templates (템플릿)
- 하는 일: Flows 기반의 완성형 크리에이티브 파이프라인(입력만 주면 실행). 현재 **beta**. 웹+모바일 앱 지원.
- 사용자 흐름:
  1. Templates 페이지 열기. Explore 탭(커뮤니티+추천; 이름 검색, Category 필터) / My Templates(내가 만든 것, 워크스페이스 공유된 것)
  2. 템플릿 선택(필요한 입력, 작성자 가이드, 예시 결과 확인)
  3. 입력 업로드(이미지, 비디오, 오디오, 텍스트 필드)
  4. Generate(입력 후 버튼에 예상 비용 표시)
  5. 결과 검토(여러 출력 가능, History 탭에 이전 실행). 생성물은 해당 제품 히스토리(Music, Image & Video 등)에도 남음.
- 카테고리: Product Shots, Mockups, Video Effects, Image Tools, Character and Portrait, Songs & Audio
- 템플릿 만들기: (a) 플로우에서 "Create Template" (b) 템플릿 페이지 "+ New Template". 단계: Input(노드/포트 선택·이름 지정, 여러 개 가능) → Output(최소 1개, 이름 지정; 2개 이상이면 zip으로 묶음 다운로드) → Publish(이름, 선택 설명·태그, 썸네일, 카테고리, 접근 범위, 최소 1개 예시 실행 선택 → 플로우를 최소 1회 실행해야 함, 1회 실행 예상 비용 표시). 게시 후 버튼은 "Update Template", 재게시 시 새 버전 생성·이전 버전 유지(API에서 버전 고정 가능).
- 공유 옵션: Just me / Workspace / Link only / Explore(검수 후 모든 사용자의 Explore 탭 노출)

## A-7. 텍스트 음성 변환 (Text to Speech) + Text to Dialogue + 모델 목록

### 7-1. Text to Speech (웹앱 Playground)
- 하는 일: 텍스트를 보이스·모델·설정에 따라 음성으로 변환. 영향도 순서: 보이스 선택 > 모델 선택 > 모델 설정.
- 사용자 흐름:
  1. Text to Speech 페이지의 입력 상자에 텍스트 입력/붙여넣기
  2. 화면 좌하단 Voices에서 보이스 선택(Default Voices, Voice Library, Voice Design 합성 보이스, IVC/PVC)
  3. (선택) 모델 선택, Voice settings 조정, Audio effects 추가
  4. "Generate speech" 클릭
  5. 다운로드: 생성 직후 우하단 다운로드 버튼, 또는 우측 패널 History 탭(좁은 화면은 Generate 위 history 아이콘)에서 다운로드 아이콘 → MP3(128kbps) 또는 WAV, "Advanced"에서 MP3 192kbps / MP3 256kbps / M4A / FLAC
- 입력·설정 항목:
  - 모델(웹): Eleven v4(`eleven_v4`), Eleven v4 Turbo(`eleven_v4_turbo`), Eleven v3(`eleven_v3`), Eleven v3 Conversational, Eleven Multilingual v2, Eleven Flash v2.5 (+ API: Flash v2, Turbo v2/v2.5(deprecated)). 모델군: Standard(고품질) / Flash(초저지연).
  - 음성 설정: Speed(기본 1.0, 0.7~1.2, 전 보이스·전 모델 해당이나 **Eleven v3 불가**, v4도 슬라이더 없음), Stability(기본 50 권장), Similarity(권장 약 75, **v3 불가**), Style exaggeration(권장 0, 지연 증가·안정성 저하), Speaker boost(**v3 불가**, 지연 증가), **Clone Strength**(PVC + Eleven v4 선택 시에만 추가 슬라이더; 낮을수록 부드럽고 유연, 높을수록 학습 녹음에 밀착; 대부분 0%에서 시작). v4는 Stability/Similarity만 사용, Style·Speed 슬라이더 없음, SSML 미지원.
  - Audio effects(Add effect, 각 유형 1회씩): Filter(전화선·오래된 라디오·로봇 등), Noise(카페·콜센터·도시·키보드 소리 등 루프 배경), Space(작은 방~홀~숲 리버브), Distance(Near/Medium/Far). Preview 버튼으로 샘플 보이스 미리듣기, 생성 후 적용, **비용 불변**. TTS 탭에서만 가능(대화는 API `audio_effects` 파라미터). API 문서에는 추가로 Pan(좌우 위치)도 있음. 스테레오가 되는 리버브·pan은 mono 출력(pcm_*, ulaw_*, alaw_*)과 조합 시 400 오류.
  - 오디오 태그(v4, v3): `[whispers]`, `[shouts]`, `[laughs]`, `[sighs]`, `[clears throat]`, 감정 `[sad]`, `[angry]`, `[happily]`, `[curious]` 등 대괄호 자연어 지시. 호흡은 `[sighs]`, `[exhales]`.
  - 일시정지: v4/v3는 SSML break 미지원(태그·문장부호로). Multilingual v2/Flash v2/Flash v2.5는 `<break time="1.5s" />`(초 단위, 최대 3초; 과다 사용 시 속도 증가/노이즈). 대체: 대시 `-`/`—`, 말줄임표 `...`.
  - 발음: v3는 IPA 네이티브 지원, Flash v2·Turbo v2는 SSML phoneme 태그(IPA/CMU, CMU가 더 예측 가능). 대체 철자.
  - 텍스트 정규화: 웹 UI는 자동 정규화(기본 활성). API는 `apply_text_normalization` = on/off/auto, `language_code`(ISO 639-1; ISO 639-3은 ast, yue, ceb, fil, kam, ckb). 웹에서는 언어 지정 불가(텍스트로 자동 감지, 한 프롬프트에 다국어 혼용 비권장). Flash v2.5는 지연 때문에 기본 정규화 꺼짐.
  - Dialogue mode(v4, v3): 웹에서 다중 화자 사용 시.
  - 언어/액센트: 언어는 텍스트가 결정, 액센트는 보이스가 결정. Eleven v4는 대상 언어가 참조 보이스 언어와 다르면 원 액센트를 따르지 않고 대상 언어로 자연스럽게 발화(의도된 변경).
  - 출력 포맷(API): MP3(22.05/44.1kHz, 32~192kbps; 44.1kHz는 32/64/96/128/192), PCM S16LE(8/16/22.05/24/44.1/48kHz), μ-law 8kHz, A-law 8kHz, Opus 48kHz(32~192kbps). 고품질 옵션은 유료 티어만.
- 한도:
  - 웹 1회 생성: Eleven v4 최대 100,000자, 그 외 모델 5,000자. 장문은 Studio 권장.
  - API 모델별: v4 100,000자(~100분), v3 5,000자(~5분), Flash v2.5/Turbo v2.5 40,000자(~40분), Flash v2/Turbo v2 30,000자(~30분), Multilingual v2 10,000자(~10분), eleven_multilingual_v1 10,000자, eleven_english_sts_v2 10,000자(Voice Changer는 Multilingual v2 기준 최대 10분 오디오).
  - 무료 재생성: 웹 TTS에서 최대 2회, 조건: 텍스트(또는 Voice Changer의 파일)·보이스·모델 동일(슬라이더 변경은 가능), 첫 생성 후 2시간 이내, 페이지 새로고침 안 함. 웹 전용(API 불가). 버튼 문구 "Regenerate speech"/"Generate speech". 미리듣기를 크레딧 없이 하는 방법은 없음(생성 시마다 차감).
  - 언어 수: 모델별 상이 - Multilingual v2 29개, Flash v2.5 32개(+Hungarian, Norwegian, Vietnamese), v3 70+, v4/v4 Turbo 90+. 
- 요금제/크레딧: TTS 1자=1크레딧(웹, v3도 1크레딧/자, API는 할인). Flash v2.5는 API 생성 시 자당 가격 50% 낮음. 무료 티어: 라이브러리 보이스 API 불가. 상업 이용은 유료 플랜(생성 오디오 소유권은 사용자, 수익화는 입력 IP 보유 시). 동시 요청 한도는 23절 "구독" 표 참조.
- 출처: D eleven-creative/playground/text-to-speech.md, D overview/capabilities/text-to-speech.md, D overview/capabilities/text-to-speech/eleven-v4.md, D overview/models.md, D eleven-creative/quickstart.md

### 7-2. Text to Dialogue (다중 화자 대화)
- 하는 일: Eleven v4/v3로 여러 화자의 표현력 있는 대화(끼어들기, 어조 변화 포함) 생성. 웹은 TTS에서 multiple speakers 사용 시 Dialogue mode, API는 Create/Stream dialogue.
- 입력·설정: 턴마다 text + voice_id. 오디오 태그를 턴 텍스트 안에 넣음(감정/전달 `[sad]` `[laughing]` `[whispering]`, 오디오 이벤트 `[leaves rustling]` `[applause]`, 전체 방향 `[football]` `[auctioneer]`). 문장부호로 끼어들기(대시)·말줄임표. `audio_effects`(API 전용, 대화 전체에 적용), `seed`(일관성), 출력 포맷은 TTS와 동일. 
- 한도: 화자 수 제한 없음. 요청당 `inputs[].text` 총 길이 2,000자 이하 권장(초과 시 분할 후 이어붙이기). 무료 재생성 2회(대시보드 한정, 동일 입력). 언어 v4 90+, v3 70+.
- 요금제: 상업적 사용은 유료. 크레딧 단가 문서에 없음.
- 출처: D overview/capabilities/text-to-dialogue.md, D overview/models.md

## A-8. 즉시 음성 복제 (Instant Voice Cloning, IVC) - 상세

- 하는 일: 짧은 샘플로 거의 즉시 음성 클론 생성. **별도 AI 모델을 학습하지 않음**(기존 학습 지식으로 "추정"). 흔한 목소리엔 잘 맞고, 매우 독특한 목소리/모델이 접하기 어려운 억양에는 한계 → 그 경우 PVC 권장. Eleven v4에서 정확도가 크게 향상(타 모델보다 원음 특성 충실 반영).
- 사용자 흐름(웹):
  1. 대시보드 왼쪽 **Voices** 섹션에서 **plus(+)** 아이콘 클릭
  2. 모달에서 **Instant Voice Clone** 선택
  3. 화면 안내에 따라 오디오 **업로드 또는 녹음**
  4. 보이스 이름·라벨 입력 + "해당 목소리를 복제할 권리와 동의가 있음" 확인(체크) 후 **Save voice**
  5. Voices > **My Voices** > **Use voice** 클릭으로 사용(TTS 열림)
  - 사용 중 IVC가 포함된 Studio 프로젝트를 InAudio/Spotify로 내보낼 때는 **보이스 인증(Verify → Voices > My Voices → "Click to verify")** 필요(Studio 문서).
- 입력·설정 항목:
  - 입력 방식: 파일 업로드 또는 앱 내 녹음(녹음용 스크립트 제공 여부는 IVC 문서에 없음; PVC 쪽엔 있음)
  - 메타: 이름, 라벨(라벨 항목 종류 IVC 문서에 없음), 복제 권리/동의 확인
  - 권장 형식: MP3 192kbps 이상(IVC 가이드 본문은 "MP3 128kbps 이상 권장, 더 높은 비트레이트는 영향 크지 않음"으로 표기 - 문서 간 수치 상이). WAV 등 비압축은 품질 향상 없고 업로드 문제를 일으킬 수 있음. "오디오 품질"은 코덱이 아니라 녹음 방식.
  - 노이즈 제거: IVC 생성 화면 옵션은 IVC 문서에 없음. 일반 팁으로 "필요 시 noise remover 사용".
  - 모델 선택/파인튠: 없음(학습 없음). 클론은 모델별 파인튠 개념 없이 Eleven v4 등 모델로 TTS.
  - 복제 후 억양/톤은 변경 불가 - 샘플을 바꿔 개선. 내보내기(standalone 파일) 불가, 계정 내에만 존재. 다른 서비스에서는 API 키로 호출 가능. 같은 오디오로 다시 만들어도 클론은 약간씩 다름 → 원본 샘플 보관 권장.
  - 언어: Flash v2.5와 Multilingual v2 지원 언어에서 복제 가능. 미지원 언어 화자도 복제는 되나 그 언어를 말하지 못함(비권장).
- 한도:
  - 권장 길이 1–2분(FAQ 일부에는 "약 1–3분", 문서 서두는 "2분 미만"). 3분 초과는 효과 거의 없고 불안정해질 수 있음(2–3분 이상은 개선 미미). 30초로 우수한 사례/10분으로 악화한 사례 언급. 샘플 개수는 무의미, 총 런타임이 중요.
  - **앱 업로드 시 파일당 최소 5초, 전체 합계 최소 10초.**
  - 권장 볼륨: -23 dB ~ -18 dB RMS, true peak -3 dB.
  - 파일 크기 한도, 최대 파일 수, 최대 길이 상한(하드 리밋): 문서에 없음.
- 요금제 제한: voices 문서 Key facts는 "대부분의 플랜에서 사용 가능", billing 문서는 "클로닝은 Starter 티어 이상에서만 가능(Free는 Voice Design용 슬롯 3개만)". 즉 문서상 IVC 최소 플랜은 Starter. 모바일 앱 기능 목록에도 IVC 포함. 보이스 슬롯 한도(커스텀 보이스 합산): Free 3 / Starter 10 / Creator 30 / Pro 160 / Scale 660 / Business 660. 보이스 작업(생성/편집) 월 한도: Free 55 / Starter 65 / Creator 95 / Pro 290 / Scale 1040 / Business 1040 / Enterprise 무제한. (자세한 내용은 23절) 
- 공유/삭제: Voice Library 공개 게시 불가. 워크스페이스 내부 공유만 가능(More actions > Share Voice). 삭제는 영구, 슬롯 반환. 
- 크레딧: 생성 비용 자체는 문서에 없음(보이스 작업 쿼터 소비).

## A-9. 프로페셔널 음성 복제 (Professional Voice Cloning, PVC) - 상세

- 하는 일: 더 큰 음성 데이터로 **전용 모델을 학습(fine-tuning)** 해 원음과 사실상 구별 불가한 클론을 만듦. 본인 목소리만 가능(노래 불가). Eleven v4에서 완전 지원(타임버, 케이던스, 억양, 전달, 음량까지 충실 재현). 보이스 라이브러리 게시·수익화는 PVC만 가능.
- 사용자 흐름(웹):
  1. 사이드바 **Voices** 옆 plus 버튼 → Voice Creation 페이지(https://elevenlabs.io/app/create-voice) → **Professional Voice Clone** 아래 **Create new**
  2. 오디오 업로드: **Upload samples** 또는 **Record yourself**(서술형·대화형·광고용 샘플 스크립트 제공, 직접 스크립트 업로드 가능). 음성 전용(노래 불가). 지원되지 않는 언어로 녹음된 샘플은 앱이 거절.
  3. 업로드 후 샘플 길이 피드백 확인(최소 1시간 이상, 이상적으로 3시간 가까이 권장 문구)
  4. 오디오 처리: 각 클립 옆 **Audio settings** 버튼 → 배경 노이즈 제거, 화자 분리(여러 화자가 섞인 경우)
  5. **음성 인증(Verify)**: 모든 업로드/녹음 후 요청됨. 가능하면 샘플 녹음과 같거나 비슷한 장비, 샘플과 비슷한 톤·전달로 진행. 화면에 나타나는 인증 문장(Voice Captcha: 짧은 텍스트를 제한 시간 내 읽기)을 **한 번만** 읽고 **Stop** 누름(여러 번 읽으면 실패 가능). 브라우저 마이크 허용/음소거 확인, 컴퓨터 마이크 녹음 음질이 업로드 샘플과 비슷해야 함. 
  6. 인증 후 학습 대기열 진입 → fine-tuning 완료 대기(My Voices에서 상태 확인, 완료 시 앱 팝업+이메일 알림)
  7. Voices 섹션 **Personal** 탭 → 클론 옆 **Use**로 사용
- 입력·설정 항목:
  - 샘플: 업로드 또는 녹음. 권장 형식 MP3 192kbps 이상(비압축 WAV는 이점 없고 업로드 문제 가능). 녹음 시 WAV 44.1/48kHz, 24bit 이상 권장, 피크 -6~-3 dB·평균 -18 dB(녹음 가이드), 최종 볼륨 -23~-18 dB RMS, true peak -3 dB. 단일 화자·배경음/리버브/음악 금지·일관된 스타일(음량·톤·억양 일관성). 한 가지 스타일만 포함 권장. 해당 PVC를 주로 쓸 언어로 말한 샘플 권장.
  - 여러 시간 분량은 ~30분 단위 샘플로 분할 업로드 권장(업로드 용이).
  - 노이즈 제거/화자 분리: Audio settings에서 클립별.
  - 학습 모델(자동): 모든 PVC는 Flash v2.5, Turbo v2.5, Multilingual v2에 자동 학습. 영어 오디오 PVC는 Flash v2, Turbo v2에도 자동 학습. Eleven v4는 대부분 자동 파인튠, 없으면 수동 트리거. 추가 모델 파인튠: My Voices에서 보이스명에 마우스오버 → 모델 목록(체크=완료, 플러스=파인튠 가능) → 모델 클릭으로 시작. 새 모델 출시 시 보이스 옆 느낌표 아이콘으로 알림. 진행률은 모델명 호버로 확인(캐시 때문에 새로고침 필요할 수 있음). 완료 시 앱 알림+이메일.
  - Clone Strength(TTS 단계, PVC + Eleven v4): 대부분 0% 권장, 독특한 억양/특성은 50%까지.
  - 이름/라벨/설명 입력 단계 존재 여부(PVC 생성 마법사 내): 문서에 상세 없음(Voice Library 게시 시에만 이름·설명·라벨 규칙이 있음 - 2절).
- 한도:
  - 길이: 최소 권장 30분, 최적 2–3시간(30–180분). "더 많을수록 좋음". 샘플 개수는 무의미, 총 런타임이 중요. 
  - 파일 크기 한도, 최대 파일 수: 문서에 없음.
  - 학습 시간: 일반 3–6시간(대기열에 따라 더 걸릴 수 있음, 최대 24시간 언급). 상태 설명 문서에서는 fine-tuning 단계가 6–24시간으로 표기(문서 간 상이).
  - 인증: 모든 시도 실패 시 24시간 후 재시도 가능, 또는 support에서 인증 횟수 리셋. 미인증 PVC 삭제는 마지막 인증 시도 24시간 후(빨리 삭제는 support), 인증 시작 전이라면 언제든 삭제 가능.
  - PVC 슬롯(Base): Free/Starter 없음 / Creator·Pro·legacy Scale 1 / Scale·legacy Business 3 / Business 10 / Enterprise 맞춤. 추가 슬롯: Voice Library에 공유한 PVC가 Studio Quality로 판정되면 자동으로 1슬롯 추가(여러 번 가능, 판정은 승인 후 자동·즉시 아님). 추가 PVC를 만들려면 이 방법 또는 Scale 이상 업그레이드.
- 상태값(My Voices 아이콘): **Draft**(생성 미완료 또는 미인증; 체크 아이콘 클릭으로 인증, More actions > Edit voice로 생성 단계 복귀) → 모델별: "The training run has been scheduled"(슬롯 대기) → "Creating dataset" → "Running fine-tuning"(퍼센트 표시) → "Voice is ready to be used with the model"; 오류 시 "We are sorry the training run experienced issues and has been retried. No further action is required"(자동 재시도; 반복 실패 시 보이스 삭제 후 처음부터 재업로드 또는 학습 오디오 교체, support 문의) ; "Click to start fine-tuning"(자동 학습 안 되는 모델은 수동 시작). 학습 전 사용 시 오류 "No model found for this voice. Please select another voice".
- 요금제 제한: PVC는 **Creator 플랜 이상** 필요. Free/Starter로 다운그레이드해도 PVC는 삭제되지 않으나 Creator 이상으로 올릴 때까지 사용 불가. Studio에서도 해지/다운그레이드 시 IVC·PVC로 오디오 생성 불가.
- 언어: Eleven v4 모델군의 90+ 언어 모두 지원(Afrikaans~Zulu 등; 전체 목록은 D help-center/product/voices/voice-cloning/what-languages-are-supported-with-professional-voice-cloning-pvc.md). v4는 샘플 언어와 같은 언어 생성 시 원 억양 유지, 다른 언어 생성 시 대상 언어로 유창하게(원 억양 비유지). v4 이전 모델은 다른 언어로 말하면 원 억양이 남음. 지원 언어 외 샘플은 거절.
- 공유/수익: Voice Library 게시 가능(PVC만) → 2절 절차. notice period(최소 30일~최대 2년, 길수록 보상 증가), Live Moderation, 이름 40자·라벨. Studio Quality 판정 시 라이브러리·ElevenReader 보상. Payouts(Stripe Connect, W-8/W-9). 비공개 공유: 워크스페이스 + "Anyone with the link" 외부 링크 공유(PVC만). 타인의 PVC 생성 불가(동의가 있어도 불가): 대신 상대가 본인 계정에서 PVC를 만들고 인증한 뒤 비공개 링크로 공유.
- 삭제/내보내기: My Voices > More actions > Delete voice(영구, 확인). 파일로 내보내기 불가(계정 내 + API 키 사용).
- 제한/금지: 본인 목소리만(인증으로 확인). 노래 불가. 복제 허용 범위: ToS·Prohibited Use Policy(합법/비유해), 생성된 모든 오디오는 사용자에게 추적 가능.
- 보이스 슬롯: PVC도 커스텀 보이스 슬롯 총량에 포함. 다운그레이드해도 보이스는 삭제되지 않지만 새 플랜 슬롯 수만큼만 접근 가능(예: 30개 → Starter 10개면 나머지 20개는 Creator로 올려야 접근).

## A-10. 보이스 디자인 (Voice Design)

- 하는 일: 텍스트 설명(프롬프트)으로 새 합성 보이스 생성. 라이브러리에 원하는 보이스가 없을 때. 탐색·반복용(품질은 프롬프트에 따라 변동, "아직 experimental"), 가장 일관된 프로덕션 품질은 PVC.
- 사용자 흐름:
  1. 앱: Voices > My Voices > Add a new voice > Voice Design (또는 API)
  2. 보이스 설명(프롬프트) 입력, (선택) 미리듣기 텍스트 입력 또는 **Auto-generate**(관련 오디오 태그 포함 자동 생성), Loudness/Guidance scale 조정
  3. **Generate voice** → 보이스 후보 **3개** 생성(크레딧은 미리듣기 텍스트 글자수만큼, 3개를 만들어도 1회만 과금; "Text to preview" 상자에 차감 글자수 표시)
  4. 후보 중 하나를 선택해 저장 → **보이스 슬롯 1개 사용**
- 입력·설정 항목:
  - 보이스 설명: **20–1000자**. 미리듣기 텍스트(선택): **100–1000자**. 
  - 권장 프롬프트 형식: "Native <Language>. <Gender>, <Age range>. <Quality level>. Persona: <2–5 words>. Emotion: <2–3 adjectives>. <1–2 sentences timbre, pacing, delivery>". 연령/음색/성별/억양/속도/감정/말투/오디오 품질을 서술. 품질 어휘: Ok / Good / Very good / Excellent / Studio / Broadcast quality("Perfect audio quality" 등). 피할 것: 억양 의미로 "accent" 사용, "reverb/echo/phone/tape" 같은 FX 단어, 언어·방언 미지정.
  - 파라미터: **Loudness**(미리듣기와 저장 보이스의 음량), **Guidance Scale**(프롬프트 준수도; 높을수록 엄격하나 틈새 프롬프트에서 음질 저하, 낮을수록 창의적. 예시 프롬프트 표에서 25%~40% 사용; 억양·톤 정확도가 최우선이면 높게).
  - 모델: Eleven v4 권장(v3도 가능, 폭넓은 감정). 보이스 디자인 모델 ID `eleven_ttv_v3`, `eleven_multilingual_ttv_v2`. 프리뷰에서 오디오 태그 지원. v4에서는 이전 모델보다 덜 연기적일 수 있음. v2 모델과 하위호환.
- 한도: 후보 3개/회, 설명 20–1000자, 미리듣기 100–1000자, 저장 시 슬롯 1개. 그 외 일일/월 생성 한도: 문서에 없음.
- 요금제/크레딧: 미리듣기 텍스트 글자 수 기준 크레딧(1회 생성=3후보). 플랜별 사용 가능 여부 문서에 없음(모바일 앱에도 Voice Design 포함). 커스텀 보이스 슬롯/보이스 작업 쿼터 적용. Voice Library 공유 불가(워크스페이스 내부 공유만). ElevenReader는 Ultra 구독자에게 무제한 Voice Design 제공.

## A-11. 음성 리믹싱 (Voice Remixing)

- 하는 일: 기존 보이스를 자연어 프롬프트로 변형(성별, 억양, 말투, 속도, 오디오 품질)해 새 보이스 변형을 만듦. 원본은 수정되지 않음. 코어 플랫폼과 API에서 제공.
- 사용자 흐름: 문서에 단계별 UI 흐름 없음. 핵심 기능으로 속성 변경, 이전 리믹스 위에 반복 편집, 기본/커스텀 스크립트, 프롬프트 강도 조절이 있음. (TTS 문서: 리믹싱은 내가 만든 보이스와 Default 보이스만 가능, 라이브러리 보이스는 불가라고 서술 - voices 문서의 "infinite notice period 라이브러리 보이스 가능"과 표현 차이 있음)
- 입력·설정 항목:
  - 입력 가능 보이스: 본인이 소유한 IVC/PVC, Voice Design 보이스, notice period가 무한인 Voice Library 보이스
  - Prompt Strength: Low(미묘한 변화) / Medium(균형) / High(프롬프트 강하게 따름, 음색 크게 변할 수 있음) / Max(완전 변환, 보이스가 완전히 바뀜)
  - 스크립트: Default scripts(리믹스에 최적화) / Custom scripts(v3 오디오 태그 `[laughs]`, `[whispers]`, `[sighs]` 등 지원)
  - 출력: v3에서 풀 퀄리티 보이스 모델(타 모델과 하위호환), 반복 리믹스 가능
- 한도: 반복 리믹스 횟수 제한 없음. 그 외 수치 문서에 없음.
- 요금제/크레딧: 요금은 리믹스 과정에서 사용한 테스트 스크립트 길이에 비례. 플랜 제한 문서에 없음. 결과물 품질은 PVC만큼은 아니고 IVC에 가까움(TTS 문서).
- 출처: D overview/capabilities/voice-remixing.md, D eleven-creative/playground/text-to-speech.md, D overview/capabilities/voices.md

## A-12. 효과음 (Sound Effects)

- 하는 일: 텍스트 설명으로 효과음(폴리, 앰비언스, 시네마틱, 짧은 음악 요소) 생성. 사이드바 Playground > Sound Effects.
- 사용자 흐름:
  1. Sound Effects 페이지(Playground 아래) 진입
  2. 텍스트 박스에 설명 입력(예: "person walking on grass")
  3. 설정: Duration(지정 또는 auto), Looping on/off, Prompt influence(기본 30%)
  4. 화살표(생성) 클릭 → **매번 4개**의 효과음 생성
  5. History 탭에서 확인 → 다운로드 아이콘으로 MP3(44.1kHz) 또는 WAV(48kHz), 별 아이콘으로 Favorites 저장, 프롬프트/설정 수정 후 재생성
  6. Explore 탭에서 커뮤니티 효과음 탐색
- 입력·설정 항목: 모델(`eleven_text_to_sound_v3` / 기본값 `eleven_text_to_sound_v2`(deprecated, 2027-03-01 제거)), Duration(자동 또는 0.1–30초), Looping(끊김 없는 루프; v2 문서 표기상 "30초보다 긴 효과음용 루프" 설명이 있으며 웹에서는 토글), Prompt influence(높음=문자 그대로, 낮음=창의적 변형), 프롬프트 팁: 단순 효과("glass breaking")는 단일 사운드+변형, 복합 시퀀스는 개별 생성 후 편집기에서 결합 권장. SFX v3는 여러 지시를 한 프롬프트에서 따르고 보컬/음악 포함, 정확한 반복 횟수 요구는 항상 지켜지지 않음. 오디오 용어 예: Impact, Whoosh, Ambience, One-shot, Loop, Stem, Braam, Glitch, Drone.
- 한도: 프롬프트 최대 450자, 길이 최대 30초/생성, 출력 MP3(전부) / WAV 48kHz(비루프만), 1회 생성=4 변형. 동시 생성: Free 4 / Starter 4 / Creator 6 / Pro 6 / Scale 8 / Business 8 / Enterprise 상향(API 기준 동시성 표).
- 요금제/크레딧: 기간을 지정하면 **초당 40 크레딧**(API 문서 표기). 비용은 설정(생성 개수·길이)에 좌우되고 텍스트 입력에는 무관. 웹과 API 요금 상이(가격표 링크). 
- 출처: D eleven-creative/playground/sound-effects.md, D overview/capabilities/sound-effects.md, D overview/models.md

### 13-2. 아바타 (Avatars)
- 하는 일: 인물/캐릭터/동물의 지속적 시각 정체성을 만들고 임의의 ElevenLabs 보이스와 결합해 립싱크 토킹헤드 영상 생성.

  2. 참조 이미지 업로드(같은 인물을 여러 각도로 3–5장 권장) 또는 텍스트 프롬프트로 묘사

  4. (선택) 스타일 생성: View Avatar → New Style → 프롬프트 또는 참조 이미지 업로드(앵글, 의상·액세서리, 배경, 조명 변형)

- 요금제: **모든 유료 플랜**. 크레딧은 립싱크 모델, 출력 해상도, 영상 길이에 따라 변동(Image & Video 가격 구조). 일부 아바타 모델/참조 이미지 업로드는 미국 제한. API는 출시 시점에 미제공(향후 계획). Flows에 Avatar 노드 있음.

## A-14. 보이스 아이솔레이터 (Voice Isolator)

- 하는 일: 오디오/비디오에서 배경 소음·음악·잡음을 제거하고 음성만 추출(영화·팟캐스트·인터뷰 후반작업). 사이드바 Audio Tools > Voice Isolator.
- 사용자 흐름: 1) Voice Isolator 앱 열기 2) 파일 업로드/드래그앤드롭 또는 마이크 녹음 3) **Isolate voice** 클릭 4) 앱에서 재생하거나 결과 파일 다운로드.
- 입력·설정: 별도 슬라이더 없음(문서에 없음). 지원 형식: 오디오 AAC, AIFF, OGG, MP3, OPUS, WAV, FLAC, M4A / 비디오 MP4, AVI, MKV, MOV, WMV, FLV, WEBM, MPEG, 3GPP. 음악에서 보컬 분리용으로 최적화되어 있지는 않음.
- 한도: 파일 최대 500MB 또는 길이 1시간.
- 요금제/크레딧: **오디오 1분당 1,000 크레딧(문자 환산)**. 플랜 제한 문서에 없음. API 제공(audio-isolation). 모바일 앱에도 포함.

## A-15. 보이스 체인저 (Voice Changer, 구 Speech-to-Speech)

- 하는 일: 원본 음성(소스)을 다른 보이스로 바꾸되 톤·감정·억양·케이던스를 보존(속삭임, 한숨·웃음·울음, 언어/액센트 유지). TTS 보완(발음 교정, 연기 주입), 성우 레인지 확장.
- 사용자 흐름:
  1. Voice Changer 페이지에서 오디오 박스 클릭/드래그로 파일 업로드, 또는 **Record Audio** → **Microphone** 버튼으로 녹음 → **Stop**

## A-16. 뮤직 (Eleven Music) + 파인튠 + 마켓플레이스

### 16-1. Music
- 하는 일: 자연어 프롬프트로 스튜디오급 음악(보컬 포함/인스트루멘털) 생성·편집. 섹션별 가사/스타일 편집, Audio Reference, Finetune 선택, 공유 링크(커스터마이즈 가능한 비주얼라이저).
- 사용자 흐름:
  1. 새 곡 설명(프롬프트). 섹션 지시(Intro, Verse, Chorus, Breakdown, Outro)로 구조 지정 가능
  2. (선택) Audio Reference 업로드: Music > Generations의 Prompt 영역 **+ Reference** 버튼
  3. (선택) Finetune 선택: Curated Finetunes(ElevenLabs 제공) / Custom Finetunes(내 오디오로 학습). 미선택 시 표준 모델
  4. 설정: Variants 수, Duration(고정 길이 예 30s/1m 또는 **Auto**). 복잡한 곡은 30초로 시작해 "+ Add Section"으로 확장 권장
  5. 편집: 가사 수정, 섹션 추가/삭제/길이 조정(타임라인 드래그), 스타일 키워드, 대화형 프롬프트("Continue the conversation..."). 같은 프롬프트로 새 변형 생성도 가능
  6. **Generate**를 눌러야 편집이 반영됨("Song composition has changed" 안내)
  7. Download 또는 Share(링크+비주얼라이저)
- 입력·설정 항목:
  - 모델: Music v2.5(`music_v2_5`, 최신, 모델 드롭다운 선택), Music v2(UI 기본), Music v1(deprecated; API 기본값은 전환기간 동안 v1이었음, 2027-01-31 제거 예정)
  - 편집 도구: Add Section(섹션 위 호버 "+ Add Section"/"Add section below", 타임라인 끝 "+"), 섹션 삭제(X 아이콘), 섹션 가사·프롬프트 텍스트 박스(대괄호 지시 예 [energetic guitar solo], [drum fill]), "Edit styles of this section" → Section styles 창에서 Include styles / Exclude styles 입력 후 Save, 인페인팅(특정 섹션만 재생성), 곡 중간 장르 전환, 빠른 랩/복잡한 보컬 전달, 곡 내 효과음 삽입
  - 보컬 언어: English, Spanish, German, Japanese 등(가사 자동 생성 또는 직접 입력). 가사 미입력 시 모델이 구조화된 가사 생성
  - Audio Reference: 짧은 트랙 최대 약 30초, 일반 오디오 포맷. 업로드마다 저작권 검수. 사운드·프로덕션 스타일·악기·템포·무드를 유도(복사/리믹스 아님, 장르 변환 도구 아님)
  - Share: 링크 + 비주얼라이저 커스텀
  - 프롬프트 팁: BPM("130 BPM")·키("in A minor") 명시 시 모델이 잘 따름, 시대/프로덕션 era 지정, "lyrics begin at 15 seconds" 같은 타이밍 표현, include/exclude 스타일
- 한도:
  - 곡 길이: 최소 3초 / 최대 **10분**(Music 제품 문서) — 단 Music capability 문서는 "최대 5분"으로 표기(문서 간 상이)
  - 출력: MP3 44.1kHz 128–192kbps(제품 문서: "다른 포맷 곧 지원"), capability 문서는 MP3 및 WAV 지원으로 표기(상이). 
  - 동시 생성(API 동시성): Free 0 / Starter 2 / Creator 2 / Pro 2 / Scale 5 / Business 5 / Enterprise 최상위(Free는 API 동시성 0)

Audio Reference: 제품 문서는 "Free 포함 모든 Music v2/v2.5 플랜", FAQ/capability 문서는 "모든 유료 플랜"(상이). 상업 이용: 구독·조건에 따라 광범위하게 허용(Music Terms 참조, 구체 티어별 내용은 문서에 없음). Zero Retention Mode는 Enterprise API에서 지원.

### 16-2. Music Finetunes (파인튠)

## A-17. 음성 텍스트 변환 (Speech to Text, Scribe) + Transcripts/Subtitles 에디터

### 17-1. Speech to Text (웹)
- 하는 일: 오디오/비디오를 텍스트로 전사(Scribe). 90+ 언어, 단어 단위 타임스탬프, 화자 분리, 오디오 이벤트 태깅.
- 사용자 흐름: 1) Speech to Text 페이지 → "Transcribe files" 2) 모달에서 오디오/비디오 업로드 3) 옵션 선택(주 언어 또는 "Detect" 자동 감지, "Tag audio events"(웃음·박수 등) 토글, Keyterm prompting 최대 1,000단어/구문(웹 문서 기준), "Include subtitles" 토글) 4) "Upload files" 5) 가운데 패널에서 파일명 클릭 → 결과 보기(단어 클릭 시 해당 지점부터 재생), 화자 이름은 "Speakers" 옆 edit로 변경 6) 우상단 Export로 다운로드 7) Transcript Editor로 편집
- 입력·설정 항목: 모델(웹 기본 Scribe v3, 데이터 레지던시 환경은 Scribe v2). 주 언어/Detect, Tag audio events, Keyterm prompting(웹 가이드: 1,000개; Scribe v3 FAQ: 100개 / 키텀 사용 시 비용 +20%로 표기 — 문서 간 상이, API 문서: 배치 최대 1,000 keyterm(각 50자), 실시간 50개/총 1,000자), 화자 분리 최대 32명, API 전용: numbers_format(digits/words), secondary_language_codes, no_verbatim(군더더기 제거), entity detection(무료, 65 엔티티 유형은 Live), transcript_edit(자연어 지시로 전사 편집, experimental, 데이터 레지던시 환경 불가, 추가 비용), 멀티채널(최대 5채널, 채널번호로 speaker ID), 웹훅(비동기 결과), 단어/문자 타임스탬프, 키텀 라이브러리·턴 예측·실시간 diarization·multilingual mode(Scribe v3 Live), 번역은 하지 않음(발화 언어 그대로).
- 한도: 웹 업로드 파일(오디오/비디오 모두) 최대 **3GB**; API는 최대 **5GB**, 표준 모드 최대 **15시간**(멀티채널은 모든 채널 합 15시간 미만). 지원 포맷: 오디오 AAC, AIFF, OGG, MP3, OPUS, WAV, FLAC, M4A, WebM / 비디오 MP4, AVI, MKV, MOV, WMV, FLV, WebM, MPEG, 3GPP. 8분 초과 파일은 내부적으로 최대 4세그먼트 병렬 처리(Concurrency = min(4, round_up(초/480))). 동시 요청: Free 8 / Starter 12 / Creator 20 / Pro 40 / Scale 60 / Business 60 / Enterprise 상향(실시간: 6/9/15/30/45/45/상향).
- 요금제/크레딧: API 과금은 오디오 길이(시간당, 요금은 티어·모델별), 무음도 과금. 웹 크레딧 단가는 문서에 없음. 키텀 프롬프팅·transcript editing은 추가 비용. Scribe v2 Medical은 Scribe v2와 동일 요금, HIPAA용 BAA는 Enterprise. 정확도 주장: 주요 언어 98%.

### 17-2. Transcript Editor (전사 에디터)
- 하는 일: STT 결과를 WYSIWYG로 편집하는 타임라인 에디터(세그먼트·화자·타임스탬프).
- 흐름/기능: STT 페이지에서 전사 클릭 → 이름 변경(우측 패널) / 텍스트 직접 편집(Cmd+Z) / 세그먼트 시작·종료 시간 타임라인 핸들 드래그 또는 우측 패널 입력 / 분할(커서 위치에서 Enter), 병합(같은 화자이고 인접한 세그먼트만) / 세그먼트 추가(Add Segment 후 타임라인 위치 선택)·삭제(Delete 키) / "align words"로 단어 타임스탬프 재계산 / 화자 재할당(개별: 오브 클릭 후 드롭다운, 일괄: ⋮ > Move Segments To) / 화자 추가(+)·삭제(삭제 시 해당 화자의 세그먼트도 삭제) / 화자 트랙 순서 변경·색상 변경 / 재생 속도 조절 / 내보내기: Plain text, JSON, HTML, SRT, VTT.
- 자막 추가: 우측 패널의 "Subtitles" 옆 "+"(또는 생성 시 "Include subtitles" 토글).
- 사람 검수 서비스(Productions): 사람 전사 **$2.00/분**부터, 원어민 검수, 선택적 Verbatim Mode([cough], [sigh], [dog barking] 등 비언어/환경음 포함). Productions는 베타·일부 사용자 한정.
- 출처: D eleven-creative/products/transcripts.md

### 17-3. Subtitle Editor (자막 에디터)
- 하는 일: Transcript Editor의 자막 모드. 자막 규칙(줄당 글자 수, 화면 줄 수, 큐 길이)을 만족하는지 실시간 빨강/초록 피드백.

## A-18. 더빙 (Dubbing) + Dubbing Studio

### 18-1. Dubbing (자동 더빙, 기본 v2)
- 하는 일: 영상·오디오의 원 음성을 다른 언어 음성으로 자동 번역·대체(원 화자 목소리 특성·감정·타이밍·톤 보존, 배경음 유지, 다중 화자 자동 감지·겹침 발화 포함). 현재 **Dubbing v2 (Alpha)**가 기본. 실시간/라이브 더빙은 미지원. 립싱크는 더빙에 미포함(Image & Video, Flows, Studio의 서드파티 모델로 제공).
- 사용자 흐름:
  1. 내비게이션에서 Dubbing 이동(https://elevenlabs.io/app/dubbing)
  2. 영상/오디오 파일 업로드 또는 **Paste URL** 탭(YouTube, TikTok 등 URL)
  3. **Choose languages**에서 대상 언어 하나 이상 선택(언어마다 과금)
  4. **Speaker similarity**(=cloning strength)로 원 화자 유사도 조정
  5. 생성 버튼 → 비용 표시·확인 → 제출
  6. 완료되면 dub 목록에서 다운로드(UI에서 transcript·번역 수정 후 개별 세그먼트 재생성 가능)
- 입력·설정 항목:
  - 모델: Dubbing v2(기본, 자동, UI 편집 가능) / Dubbing v1(레거시; **Dubbing v1 선택 후 "Dubbing project"**를 고르면 Dubbing Studio 프로젝트 생성. 기존 자동 더빙을 Dubbing project로 전환은 불가)
  - Cloning strength(Speaker similarity): 0–10, 기본 **7**. 높을수록 원 화자 유사도 우선(언어 간 음성적 차이가 크면 덜 자연스러울 수 있고 원 억양이 더 남음), 낮을수록 대상 언어 자연스러움 우선.
  - 언어: 90+ 언어. API는 BCP-47(`source_language`, `target_language`, 예 `fr`, `es-MX`). v2는 방언 지원: ar-EG, zh-TW, en-AU/CA/GB/US, fr-CA/FR, pt-BR/PT, es-AR/CL/ES/MX(그 외는 기본 코드). v1은 Eleven v3 모델과 같은 언어, 방언 미지원. v2 언어에는 Afrikaans, Akan, Albanian, Amharic, Arabic, Armenian, Assamese, Azerbaijani, Basque, Belarusian, Bosnian, Bulgarian, Burmese, Cantonese, Catalan, Cebuano, Chinese, Croatian, Czech, Danish, Dogri, Dutch, English, Estonian, Filipino, Finnish, French, Galician, Georgian, German, Greek, Gujarati, Hausa, Hebrew, Hindi, Hungarian, Icelandic, Indonesian, Italian, Japanese, Javanese, Kannada, Kazakh, Kikuyu, Kinyarwanda, Kirundi, Korean, Kyrgyz, Latvian, Lithuanian, Luganda, Macedonian, Malay, Malayalam, Mandarin Chinese, Marathi, Mongolian, Nepali, Norwegian, Persian, Polish, Portuguese, Punjabi, Romanian, Russian, Sepedi, Sesotho, Sindhi, Slovak, Slovenian, Spanish, Sundanese, Swahili, Swati, Swedish, Tajik, Tamil, Telugu, Thai, Tibetan, Tsonga, Tswana, Turkish, Ukrainian, Urdu, Uyghur, Uzbek, Venda, Vietnamese, Waray, Welsh, Wolof, Yoruba, Zulu 등이 포함됨.
  - 업로드 지원 포맷: AAC, AIFF, AVI, FLAC, M4A, M4V, MKV, MOV, MP3, MP4, MPEG, MPG, OGA, OGG, OPUS, WAV, WEBA, WEBM, WMV, 3GPP (비디오 최대 4K).
  - 출력: v2는 단일 무손실 오디오 파일. Dubbing Studio(v1)는 MP4, AAC, AAF, SRT, WAV(화자별 트랙 zip). 더빙된 비디오는 "프리뷰"이며 보통 1080p(원본 해상도와 다를 수 있음), 오디오는 v1 모노/v2 최대 스테레오(5.1 등 멀티채널 미보존). 프로덕션에서는 더빙 오디오를 원본 영상 오디오 트랙에 교체 권장.
- 한도:
  - 업로드: 웹 Dubbing v2는 **2GB와 180분 모두 미만**(FAQ) — 단 capability 문서는 "앱 1GB·180분, API 파일당 3GB"로 표기(문서 간 상이). Dubbing Studio(v1)는 1GB·45분.
  - 화자: 파일당 최대 **32명**. 
  - 동시 작업: 모든 셀프서브 플랜(Free~Business) 최대 **3개**, Enterprise 기본 **10개**(워크스페이스 단위, 모델별 별도 카운트, 초과 시 `too_many_concurrent_requests`).
- 요금제/크레딧: 모든 플랜(무료 포함) 사용 가능. **무료 플랜 dub은 자동 워터마크**(제거 불가), 유료는 워터마크 없음(v2에는 워터마크 토글/크레딧 할인 옵션 없음; v1·Studio에만 있었음). 과금은 **소스 미디어 분당 × 대상 언어 수**(모델별 요율, 앱에서 확인 후 시작). API 프로젝트는 생성 시 1개 언어분 선결제(최소 1언어), 추가 언어는 별도. 실패 시: 준비 실패는 환불, 추가 언어 실패는 환불, 첫 언어 실패는 선결제 환불 없이 같은 프로젝트에서 재시도 시 추가 비용 없음. 실행 중인 dub은 삭제해도 환불 없음. Dubbing v2는 실패 작업 과금 없음(분당 USD 과금). 해지/다운그레이드 시 IVC/PVC 등 유료 기능 사용 불가(데이터는 삭제 안 함). API: dub 생성·다운로드는 모든 플랜, **transcript 편집·오디오 재생성(API)은 Enterprise 전용**.

### 18-2. Dubbing Studio (레거시, 유지보수 모드)
- 하는 일: v1 모델용 세밀 편집 도구(트랜스크립트·번역 편집, 화자 재할당, 클립별 재생성). **maintenance mode**(치명적 버그만 수정, 신규 기능 계획 없음).
- 사용자 흐름: 1) Dubbing v1 모델 선택 → Dubbing project 2) **Create Dub** → 생성 후 ⋮ > **Edit**로 열기 3) Speaker Cards에서 원문 전사/번역 편집(Transcribe Audio로 재전사, 화살표로 재번역) 4) 타임라인에서 클립 길이 조절·리프레시 아이콘으로 클립 재생성 5) 보이스 선택·설정 6) Export
- 입력·설정 항목: 
  - 타임라인 이동: 커서 드래그, 가로 스크롤, 타임코드 입력. 클립 분할(Split)/병합(Merge), 다른 화자 트랙으로 드래그해 재할당, 오디오 트랙 추가.
  - 재생성 모드: Fixed Generations(기본; 클립 길이 고정, 텍스트 대비 길이 불일치 시 속도 변화) / Dynamic Generations(우클릭; 텍스트에 맞게 길이 조정, 싱크 영향 위험). Stale Audio(변경으로 재생성이 필요한 클립) → "Generate Stale Audio"로 일괄 생성. Clip History(우클릭)로 이전 생성 선택.
  - 보이스: Clip clone(클립별 클론) / Track clone(화자 트랙 전체 소스로 클론, 기본) / Voice Library 보이스. "Create Voice from Selection"로 클립에서 보이스 저장. 보이스 설정은 Track level 또는 Clip level("inherit track settings" 해제).
  - 추가 기능: Voiceover Tracks(새 화자, 번역 후 Generate, 마이크 아이콘으로 내 목소리를 보이스 체인저로 변환), SFX Tracks(프롬프트로 효과음 클립 생성), Upload Audio(무음성 트랙: SFX/음악/배경; 음성이 있어도 감지 안 됨).
  - Manual Dub: 정확한 대본이 있을 때 생성 시 **Manual mode**. 필요: 비디오 파일, 배경 오디오 파일, 전경 오디오 파일, CSV(speaker, start_time, end_time, transcription, translation). 지원 시간 형식 3종: seconds / hours:minutes:seconds:frame / hours:minutes:seconds,milliseconds.
  - Export: AAC, MP3, WAV, 오디오 트랙 zip, 오디오 클립 zip, AAF(타임라인), SRT, CSV(speaker, start_time, end_time, transcription, translation). 올바른 언어 선택 후 내보내기.
- 한도: 업로드 1GB·45분. 그 외 문서에 없음.
- 요금제: 모든 플랜 가능(무료는 워터마크). 크레딧은 분당×언어(위 18-1과 동일 FAQ). 작업 실패/취소 시 크레딧 자동 환불.

## A-19. 오디오북 (Audiobooks)

- 하는 일: 원고(EPUB/PDF)를 스튜디오 품질 오디오북으로 만드는 엔드투엔드 워크플로(챕터 구조, 보이스 캐스팅, 발음 규칙, 음악·효과음, 편집, 내보내기, ElevenReader 등 게시). Dynamic narration(청취자가 재생 중 보이스 선택)도 지원.

  1. Audiobooks 페이지 **Create an Audiobook**
  2. 원고 업로드(드래그앤드롭/찾아보기): **EPUB, PDF**
  3. 내레이션 스타일: **Single cast**(한 명이 전체) / **Multi cast**(내레이터 + 원고에서 감지된 캐릭터별 보이스)
  4. 모델 선택(추천: Eleven Multilingual v2 (Studio Quality), 29개 언어) → **Continue**
  5. 파싱 → **Formatting** 화면: 표지 자동 추출(교체/제거/유지), 감지된 섹션(저작권, 헌정, 프롤로그, 챕터, 에필로그 등) 체크박스로 포함 선택(자동 감지 오류 가능)
  6. **Characters** 단계: Multi cast면 AI가 캐릭터 감지 → 내레이터·각 캐릭터·기타 화자에 보이스 할당. Voice Library 탐색(필터: Language, Accent, Category, Gender, Age; 미리듣기, **커스텀 오디오로 미리듣기는 크레딧 사용**). 캐릭터 감지는 출발점일 뿐(소수·무명 캐릭터 누락 가능).
  7. **Pronunciations** 단계: 자동 제안 용어 검토 → 규칙(Alias + Output) 추가 / **Add rule**로 수동 추가 / Play 아이콘으로 원고 문장 속에서 미리듣기(빈 규칙은 무시)
  8. 우하단 **Create audiobook**
  9. 에디터에서 편집·재생성, 완료 후 Export 또는 Publish
- 입력·설정 항목:
  - 모델: Eleven v4, Eleven v3, Eleven Multilingual v2(기본), Flash 모델군. 모델 변경은 이미 생성된 오디오를 갱신하지 않으며 영향 단락 재생성(크레딧 소모) 필요. 기본 언어는 자동 감지. 기본 보이스는 자동 선택(변경 가능).
  - 에디터 사이드바(선택 단락): Playback controls(Volume, Fade in/Fade out), Voice & model 선택, Override settings(해당 단락 한정), Generation history, AI tools(Enhance text, Remove background audio(보이스 아이솔레이터), Use voice changer, Direct speech with your voice(Actor Mode)). 프로젝트 기본값은 좌상단 메뉴 > Project settings.
  - 재생 모드: Until end (generate one at a time) / Until end (generate clips ahead). 단락 상태 막대: 진한 막대=생성됨, 연한 회색=미생성. 이미 생성된 오디오 재생은 무료.
  - 오디오 레이어: Voices, SFX(라이브러리 또는 생성), Music(Music Marketplace 선택 또는 생성). "+" 아이콘으로 가져와 별도 트랙(타임라인).
  - 발음 사전: Phoneme rules(영어 모델 예 Flash v2에서만) / Aliases, 사전은 순서대로 적용(첫 매칭 규칙 사용), Pronunciations Editor(툴바)에서 사전 생성·선택·파일 업로드, **Connect**. 변경은 새로 생성되는 오디오부터 적용.
  - 챕터: + 버튼으로 추가, 이름 변경·재정렬, 챕터별 생성. 문서 가져오면 자동 감지.
  - 내레이션 모드: Original audio(고정 음성) / Dynamic narration(청취자가 보이스 선택; 음악·효과음·외부 오디오는 포함되지 않음).
  - Export(Publish > Export 탭): 범위(전체/개별 챕터), 미디어(Audio, Timeline data(AAF), Subtitles), 구조(단일 파일/챕터별 ZIP), 오디오 포맷 **MP3, WAV**. 미생성 구간은 내보낼 때 자동 생성(크레딧 소모). 오디오 품질은 플랜·프로젝트 설정으로 자동 결정(크레딧 영향 없음), Audio format 필드 호버로 비트레이트·샘플레이트 확인.

- 한도: 캐릭터 감지 보이스 **최대 150개/권**(보이스 사용 총수는 제한 없음). 매우 큰 원고는 처리 실패 가능(수치 한도 문서에 없음). 지원 파일 EPUB·PDF만. Voice Library 10,000+ 보이스, 90+ 언어 내레이션.

## A-21. 에이전트 (ElevenAgents)

- 하는 일: 음성인식(ASR) + 선택한 LLM(또는 커스텀 LLM) + 저지연 TTS + 자체 턴테이킹 모델을 하나로 묶은 음성/텍스트(멀티모달) 에이전트 플랫폼. 대시보드(https://elevenlabs.io/app/agents), API, CLI, 호스티드 MCP로 관리. 비주얼 워크플로 빌더 제공. 별도로 Realtime 모델(`eleven_realtime_v1_mini`/`_max`)과 Speech Engine(BYO LLM) 선택지가 있음. 출처: D eleven-agents/overview.md, D overview/models.md
- 사용자 흐름(웹 대시보드 퀵스타트):
  1. elevenlabs.io 로그인 → ElevenAgents 대시보드에서 새 어시스턴트 생성(이름 입력, "Blank template" 선택)
  2. **Agent** 탭: First message(첫 발화), System prompt(성격·업무·가이드라인) 설정
  3. **Knowledge Base** 섹션에 문서·링크 업로드
  4. **Voice** 탭에서 보이스(라이브러리) 선택(고품질 보이스·모델·LLM은 응답 지연 증가 가능)
  5. **Test AI agent** 버튼으로 대화 테스트
  6. **Analysis** 탭: Evaluation criteria(성공/실패/미확인 + 근거, 예 `solved_user_inquiry`), Data collection(data type 예 string, identifier, description)
  7. **Call history**에서 평가 결과·수집 데이터 확인
  8. 배포: 위젯 임베드 / 전화번호 연결 / SDK
  - 대안: 코딩 에이전트 온보딩(`npx -y @elevenlabs/cli@latest onboard init`), CLI(`elevenlabs agents pull/push`, agents as code), 호스티드 MCP(`https://api.elevenlabs.io/v1/mcp`).
  출처: D eleven-agents/quickstart.md, D eleven-agents/customization/widget.md
- 입력·설정 항목:
  - 기본 구성: 시스템 프롬프트, 첫 메시지, 언어(31+ 언어 에이전트 / 문서에 따라 TTS는 70+ 언어, 10,000+ 보이스), 다국어 시 언어별 보이스 지정, 멀티보이스(한 대화에서 보이스 전환), 발음 사전(IPA/CMU; 음소 기반은 Flash v2 모델에서만), 속도 0.7x–1.2x, Expressive mode(Eleven v3 Conversational + 개선 턴테이킹), Audio environment(루핑 배경음 + 전화풍 필터), **라이브 모더레이션 보이스는 에이전트에서 사용 불가**.
  - 모델: Voice mode = Custom(LLM·TTS·ASR 직접 선택) 또는 Realtime(`eleven_realtime_v1_mini` 기본·최저 지연/비용, `eleven_realtime_v1_max` 복합 지시·다단계 툴 사용, 더 비쌈; 점진 롤아웃 중이라 일부 워크스페이스에서 미노출). 지원 LLM: ElevenLabs 호스팅(Nemotron 3.5 Super VL, DeepSeek Flash 4.1, GLM 5.2, Qwen3.6/3.5 등), Google Gemini(2.5 Flash/Flash Lite~4 Argon 등; Gemini 2.5 Flash·Flash Lite는 2026-11-30 제거 예정, 11-15부터 단계적으로 3.5 Flash/Flash-Lite로 이동), OpenAI GPT-4o~GPT-6.1 계열, Anthropic Claude Haiku 4.5/Sonnet 4.5~5.5/Opus 4.6~5.5, 커스텀 LLM(엔드포인트+시크릿 저장소). 온도 0.0–1.0 구간 설명(낮음 0–0.3, 중간 0.4–0.7, 높음 0.8–1.0), 백업 LLM 캐스케이드(기본/커스텀/비활성), 최대 시스템 프롬프트 2MB(지식베이스 내용 포함). 일부 모델은 EU 데이터 레지던시에서 사용 불가.
  - 대화 흐름(Advanced 탭): Max conversation duration(기본 600초(10분), 범위 60–7,200초; WhatsApp 메시지 대화는 기본 15분 무응답 타임아웃), Take turn after silence(turn_timeout 1–30초; 캐주얼 5–10초, 복잡한 응답 10–30초 권장), Soft timeout(LLM 지연 시 "Hmm..." 같은 필러를 턴당 1회), Interruptions on/off, Turn eagerness, Noisy environment detection.
  - 워크플로(비주얼 빌더) 노드: Subagent(시스템 프롬프트 추가/덮어쓰기, LLM 변경, 보이스 변경, 노드별 지식베이스·도구 포함/추가), Say(Literal: 고정 문구+언어별 번역 / Prompt: LLM 생성), Dispatch tool(성공/실패 경로), Update state, Agent transfer, Transfer to number, End. 엣지: Forward/Backward, LLM Condition(자연어 조건), Expression(결정적 조건), None(기본 경로).
  - 지식베이스(Knowledge base): 문서 출처 = 파일/URL/텍스트. 파일 형식 **PDF, DOCX, TXT, MD, HTML, EPUB, 파일당 최대 20MB**. 사용 모드 `auto`(기본: RAG 활성+인덱싱되었으면 RAG, 아니면 풀 컨텍스트) / `prompt`(항상 프롬프트에 포함). 풀 컨텍스트는 추출 텍스트 약 300,000자 이내만 가능. 폴더는 항상 RAG(에이전트에서 RAG 활성 필요). 한 문서를 여러 에이전트에 연결 가능. RAG: 지연 약 +250ms, 설정 `embedding_model: e5_mistral_7b_instruct`, `max_vector_distance: 0.6`, `max_documents_length: 50000`, `max_retrieved_rag_chunks_count: 20`. 500바이트 미만 문서는 RAG 인덱싱 불가(프롬프트로 자동 사용).
  - RAG 총 문서 크기 한도(워크스페이스, 원본 파일 크기 기준): Free 1MB(비활성 시 인덱스 삭제 가능) / Starter 2MB / Creator 20MB / Pro 100MB / Scale 500MB / Business 1GB / Enterprise 1GB(협의로 상향).
  - 도구(Tools): Client tools(앱/브라우저가 실행), Webhook tools(ElevenLabs가 서버 호출; 결제·신원 등 신뢰가 필요한 로직용), Code tools(ElevenLabs 인프라 샌드박스의 JavaScript), MCP tools(외부 MCP 서버), System tools: End call, Language detection, Agent transfer, Transfer to number, Skip turn, Play keypad touch tone, Voicemail detection, Update state(+ Flag issue for review). 도구 호출 효과음, 도구 호출 중 인터럽션 허용 설정.
  - 개인화: Dynamic variables(런타임 값 주입), Overrides(language, first_message, system_prompt, voice_id; 에이전트 보안 설정에서 오버라이드 허용 필요), 인증(Authentication; 위젯은 인증 비활성 공개 에이전트 필요), Twilio 개인화.

## A-23. 구독 / 요금제 / 크레딧 / 보이스 슬롯

- 하는 일: 플랜(구독) + 월 크레딧 쿼터 + 보이스 슬롯 + 동시성 + 출력 품질 + 상업 이용 권한을 결정. 가입 시 자동으로 Free. 구독 확인: 프로필 아이콘 > Subscription(https://elevenlabs.io/app/subscription), 하단 비교표. 출처: D overview/administration/billing.md
- 플랜 구성: 공개 플랜 Free, Starter, Creator, Pro, Scale, Business(문서 문장에는 "five"라고 쓰고 6개를 나열 — 문서 표기 오류로 보임) + Enterprise(대규모 조직 맞춤). **플랜별 월 가격(USD)과 플랜별 월 크레딧 총량은 문서에 없음**(가격 페이지 링크만 제공; 예외로 Starter 월 쿼터는 30,000 크레딧으로 롤오버 예시에서 확인, 무료 월 10,000 크레딧/자). 
- 결제 방식: 구독(월/연, 연간 플랜은 모든 티어 제공, 분기 플랜 없음) / Pay As You Go(선불). 결제수단: 신용카드, Apple Pay, Google Pay, UPI(인도 한정). 인도 거주자는 INR 결제 가능(그 외 USD). 선불카드는 비공식 지원. 인보이스: Subscription > Billing > View invoices. 환불: 결제 후 **14일 이내이고 해당 기간 크레딧 미사용**일 때.
- 사용자 흐름:
  1. 업그레이드: 언제든 가능(이전 플랜 미사용 크레딧은 새 플랜으로 이월). 연간→연간 업그레이드만 가능(연간→월간 불가), 연간 업그레이드 시 남은 기간 비례 할인(연간 가격에 포함된 2개월 무료분 차감)
  2. 다운그레이드/해지: Subscription > Billing > Modify Plan에서 선택, **현재 청구 주기 종료 시 적용**, 미사용 크레딧은 소멸. 해지 후 주기 내 "Resume subscription"/"Cancel downgrade"로 철회 가능. 구독 일시정지는 불가(해지 시 Free로 전환, 데이터 삭제 안 함). 해지하면 이후 청구 주기 종료 시점 Free.
  3. 크레딧 소진 알림: Subscription > Manage Subscription > "Enable credit usage notification" 슬라이더로 임계 퍼센트 설정(멀티시트 워크스페이스는 모든 관리자에게 이메일)
- 크레딧:
  - 이전 명칭 "characters"와 동일 가치. TTS는 1자=1크레딧(웹), 그 외 기능은 길이/모델/웹·API에 따라 다름(가격 페이지). 대표 수치(문서 기재): Voice Changer·Voice Isolator 분당 1,000, 효과음 지정 길이 시 초당 40, Voiceover Studio SFX 클립 생성당 80, 번역 1크레딧/자 등.
  - 월 리셋: 구독 갱신 결제 처리 후(가입일 기준 매월 같은 날, 31일 가입자는 말일). 롤오버: 같은 구독을 유지하는 한 **월 쿼터의 최대 2배까지** 이월 → 보유 최대 = 월 쿼터 x 3(예: Starter 30,000 x 3 = 90,000). Free는 롤오버 없음. Enterprise 연간 계약은 연 단위 일괄 지급(리셋 연 1회, 최대 2개월분 이월).
  - **한 번에 사용할 수 있는 크레딧 상한: 월 쿼터의 2배**(남용 방지).
  - 모바일 앱 구독: 롤오버 월 할당량 2배, 해지/다운그레이드 시 사이클 종료 때 소멸(5절).
  - 상업 이용: 유료 플랜은 상업 권리. Free는 비상업·출처 표기. 구독 종료 후에도 구독 중 생성한 콘텐츠의 상업 라이선스는 영구 유지, 구독 밖에서 생성한 오디오는 항상 출처 표기 필요. 생성 콘텐츠 접근은 무기한 보장 안 함. 
  - 남용 방지: 무료 티어에서 비정상 활동(프록시/VPN, 공유 IP) 감지 시 "Unusual activity detected. Free Tier usage disabled" 표시, 유료 구독은 영향 없음. 무료는 사용자·IP당 계정 1개.
- Pay As You Go(PAYG, Top Up):
  - 자기 계정 > Developers 설정 > Top Up. 모든 셀프서브 플랜(Free 포함) 사용 가능, Enterprise 및 레거시는 제외. 구독 크레딧을 먼저 소진한 뒤 PAYG 잔액 사용. 잔액은 USD/INR 달러값으로 저장되고 플랜 요율로 크레딧 환산(플랜 변경 시 크레딧 수가 변할 수 있음).
  - 한도: 최소 Top Up $5 / ₹500, 통화 USD·INR, 월 최대 Top Up 횟수 **250**, 2FA 미사용 시 월 구매 상한(Free·Starter·Creator $100 / Pro $200 / Scale $600 / Business $2,000; INR는 ₹8,800/17,600/52,800/176,000), 크레딧은 구매 후 **12개월 만료**, 환불 불가, 잔액 $0이면 서비스 즉시 중단(후불 없음). Auto Top Up: 기본 충전액 $20(₹2,000), 기본 임계 $10(₹1,000), 최소 잔액 $5(₹500) 필요, 결제 실패 시 중단. 
  - 무료 플랜+PAYG: 동시성 3, 우선순위 4(Starter 수준). 보이스 슬롯 등 플랜 한도는 구독 플랜 기준. PAYG는 Music, Sound Effects 등 무료 플랜에서 막힌 API를 해금.
  - 사용량 기반 과금(overage)은 레거시/Enterprise 한정: 한도 초과분 추가 크레딧 구매(1,000 크레딧 단위 고정가), 임계 설정, 초과 청구액이 월 구독료의 2배를 넘으면 즉시 청구. 신규 셀프서브에는 제공 안 됨(PAYG로 대체, "Switch to new pricing"으로 전환 후 되돌리기 불가).

## A-24. 워크스페이스 · 관리

- 하는 일: 팀 공동 사용(공유 결제, 공유 리소스, 접근 관리, API 키 관리, 다중 워크스페이스 멤버십). 출처: D overview/administration/workspaces/overview.md
- 생성/구성: 멀티시트 워크스페이스는 Scale, Business, Enterprise 구독에 자동 활성(Scale/Business는 계정 소유자가 기본 관리자, Enterprise는 설정 시 관리자 지정). 워크스페이스당 소유자 1명(이전 가능). 한 사용자가 가질 수 있는 **무료 워크스페이스는 1개**, 유료 워크스페이스 멤버십은 제한 없음. 워크스페이스 전환: 계정 메뉴의 스위처.
- 멤버 관리(Workspace settings > Members): 관리자만 추가·제거·권한 부여. 시트 종류: **Full Seat**(ElevenCreative·Agents·API 전체, 월 개별 상한 없음, 공유 풀 사용, 개인 API 키 생성) / **Basic Seat**(Agents·API 위주, ElevenCreative 생성은 사용자당 결제 주기 **50,000 크레딧**(Enterprise는 월 $5 사용분) 상한을 공유 풀에서 소비, 열람은 항상 가능, 한도 도달 시 ElevenCreative 생성 불가·Agents/API는 영향 없음). 관리자는 항상 Full Seat. Full→Basic 전환 시 Full 시절 사용량도 상한에 산입. 플랜별 포함 시트는 23절 표. Pro/Scale/Business는 Full Seat 추가 구매 가능(총 최대 11, 즉시 비례 과금, 시트마다 공유 풀 크레딧 증가, 제거는 다음 갱신 때 적용·환불 없음; 연간 플랜은 연 단위 과금하나 크레딧은 월 지급), Free/Starter/Creator는 추가 구매 불가. 업그레이드 시 구매 시트는 새 플랜의 포함 시트에 흡수. Enterprise는 계약으로 Full Seat 수 결정·추가 시트 비용이 월 약정에 가산. 
  - 역할(Enterprise): User Manager(멤버 초대·제거, 그룹 멤버 관리), Resource Manager(Voices, Studio projects, Sound effects, Dubbing 리소스 관리; Agents 제외). 관리자에게는 부여 불가.
  - 초대: Enterprise는 도메인 인증 후 대량 초대·사용자 자동 프로비저닝(검증된 도메인 이메일로 가입 시 자동 가입·시트 점유). 2FA 필수화(Enterprise 관리자, Require Two-Factor Authentication).
  - 사용자 그룹: 관리자만 생성·편집·삭제, 중첩 불가, 다중 소속 시 권한 합집합. 그룹 단위로 PVC·Sound Effects 등 기능 권한을 끌 수 있음(Everyone 그룹에서 권한 제거 후 그룹별 부여). 
  - 빌링 그룹(관리자 전용): 그룹 단위 **크레딧 쿼터와 PVC 개수 상한**(독립 적용), 사용자/서비스 계정은 한 그룹에만 소속, 크레딧 한도는 결제 주기마다 리셋·PVC 한도는 리셋 없음, 한도 도달 시 그룹 멤버 전원 요청 차단(관리자가 올려야 함), 가입 이후 사용분부터 집계(소급 없음), 한도 없이 사용량만 추적도 가능. Workspace settings > Groups.
- 리소스 공유: 공유 가능 리소스 = Voices, Pronunciation Dictionaries, Dubbings, Projects, Auth Connections, Files and Folders, Agents(Knowledge Base Documents, Tools, Settings, Secrets, Phone Numbers, MCP Servers, Batch Calls, Response Tests, Test Suite Invocations, WhatsApp accounts 포함). 대상(principal) = 사용자 / 사용자 그룹 / 서비스 계정, **리소스당 최대 100개 대상**. 역할: Viewer(발견·사용; 예 TTS 생성/Studio 재생) / Editor(편집) / Admin(삭제·공유 관리). 만든 사람은 Admin이며 다른 Admin이 박탈 불가. 워크스페이스 관리자는 모든 리소스에 Admin 권한. 기본 공유 설정(개인 설정 Default Sharing Preferences)으로 새 리소스를 자동 공유. 
  - 리소스 복사: 소유자 및 "Copy Resources Between Workspaces" 권한자가 Voices, Studio projects, Dubs, Basic Agent Configs(시크릿 제외), Pronunciation Dictionaries를 다른 워크스페이스로 복사(설정에서 전체 일괄 또는 workspace resources 페이지에서 개별). Enterprise는 같은 consolidated billing group 내로 한정, 기본 비활성이며 소유자가 "Enterprise Copying"을 켜야 함.
- 서비스 계정 / API 키: 멀티시트 고객 전용, 관리자만(Workspace settings > Service Accounts). 생성 직후 접근 권한 없음 → 그룹 추가 또는 리소스 직접 공유로 부여(그룹 권장). API 키는 서비스 계정 소속, 스코프·크레딧 쿼터·IP 허용 목록 지원, 만료 없음. 사용자 키는 만료 설정 가능(15분–30일). IP 허용 목록은 IP/CIDR 형식(공인 IP만), 차단 시 403, 공개적으로 노출된 키는 자동 비활성(`disable_reason: exposed_publicly`) → 키 로테이션. 출처: D overview/administration/workspaces/api-keys.md, service-accounts.md

  - SSO: SAML 2.0 및 OIDC, SP-initiated만(Entra는 SAML만, OIDC 사용 금지), 도메인 DNS TXT 인증 필수, Allowed Identity Providers로 로그인 수단 제한 가능, 저장 시 SSO로 로그인한 모든 멤버 즉시 로그아웃. 북마크 URL `https://elevenlabs.io/app/sign-in?use_sso=true`. Enterprise 전용.
  - Audit logs: Enterprise + `audit_log_read` 권한 API 키, `GET /v1/workspace/audit-logs`, OCSF v1.6.0 스키마(datetime, host 프로필), 100개 이상 엔드포인트 커버, 사용자당 분당 30회, limit 최대 100(분당 최대 3,000건). 이벤트 클래스: Account Change(3001), Authentication(3002), Entity Management(3004), User Access Management(3005) 등.

  - 데이터 레지던시(Enterprise): 기본 저장 위치 미국, 격리 환경 EU(eu.residency.elevenlabs.io)/인도(in.)/싱가포르(sg.) — 완전히 별개 워크스페이스·계정(웹/API/WebSocket 주소 별도). 처리는 지역 밖에서 일어날 수 있음(EU는 Zero Retention Mode+API로 EU 내 처리 제한 가능). 격리 환경에서는 Studio Agent 불가, STT는 Scribe v2, transcript editing 불가, 일부 에이전트 LLM·Realtime Max(인도/싱가포르) 제한. 컴플라이언스: GDPR, SOC2, Zero Retention Mode(선택), 전송 구간 암호화, HIPAA BAA(해당 기업).
