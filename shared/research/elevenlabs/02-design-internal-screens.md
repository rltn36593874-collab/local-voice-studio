## 1. 앱 셸 (모든 화면 공통)

```
┌──────────┬──────────────────────────────────────────────────────────────┐
│ 사내 음성  │ 상단 바:  [화면 제목]                 [⚙ 작업 1 · 대기 2] [✳ Claude 32%] │
│ ──────── ├──────────────────────────────────────────────────────────────┤
│ ① 음성 만들기│                                                              │
│ ② 받아쓰기  │  작업 영역(화면별)                                              │
│ ③ 보고서 브리핑│                                                           │
│ ④ 목소리 복제│                                                              │
│ ⑤ 기록     │                                                              │
│ ──────── │                                                              │
│ (하단) CPU 상태│                                                            │
│ 모델 준비됨  │                                                              │
└──────────┴──────────────────────────────────────────────────────────────┘
                                      └─ 작업 패널(오른쪽 서랍, 상단 '작업'을 누르면 열림)
```

- **왼쪽 메뉴**: 220px. 메뉴 5개 외에 다른 것은 두지 않는다. 메뉴 옆에 진행 중인 작업 점(●)을 표시한다.
- **상단 바**: 52px. 화면 제목, 작업 표시기, Claude 사용량 미터만 둔다.
- **작업 영역**: 최대 폭 1120px, 좌우 여백 32px. 1280 폭에서는 메뉴 220에 작업 영역 1060이다.
- **메뉴 하단 상태 줄**: 로컬 모델 상태를 표시한다(준비됨 / 불러오는 중 / 오류). CPU 모델이 메모리에 없으면 첫 작업이 느리다는 것을 미리 알리는 용도다.

## 2. 공통 요소

### 2-1. AI 생성 배지

| 상태 | 표시 | 쓰는 곳 |
|---|---|---|
| 기록됨 | 테두리 배지 "AI 생성" + 반짝임 아이콘(중립색) | 모든 결과 플레이어, 기록 목록 행 |
| 복제 음성 | 배지 옆에 "복제 음성" 배지를 추가 | ④로 만든 목소리를 쓴 결과 |
| 누락(경고) | 경고색 배지 "AI 표시 누락" + [다시 기록] | 메타데이터 쓰기 실패 시(기록 화면) |

- 결과 플레이어마다 **[설명란 문구 복사]** 버튼을 둔다(기획 §2 AI 생성 표시). 복사하면 1.6초 동안 "복사됨"을 표시한다.
- 파일명 규칙 [제안]: `YYYYMMDD-HHMM_종류_제목_AI.mp3`.

### 2-2. CPU 처리 진행률·대기열

- **원칙**: 로컬 작업은 한 번에 하나씩 처리한다(기획 §4 메모리 규칙). 나머지는 대기열에 들어간다.
- **세 곳에 같은 작업 정보를 보여 준다**:
  1. **화면 안 작업 카드**: 그 화면에서 맡긴 작업. 단계명, 진행률 바, %, 경과, 예상 남은 시간, [취소]
  2. **상단 작업 표시기**: "작업 1 · 대기 2". 작업이 없으면 "작업 없음"을 흐리게 보인다.
  3. **작업 패널(서랍)**: 진행 중 1개와 대기 목록(순번, 종류, 제목, [취소]), 최근 완료 5개(결과로 이동)
- **작업 카드 상태**:
  - 대기 중: "앞에 2개 작업이 있어요"
  - 준비 중: 모델 불러오기
  - 처리 중: % 표시
  - 완료
  - 실패: 원인과 [다시 시도]
  - 취소됨
- **화면 이탈**: 작업은 화면을 나가도 계속된다. 끝나면 상단에 토스트로 "받아쓰기가 끝났어요 → 보기"를 띄운다.
  - 기획 §4의 "걸어 두고 나중에 받기"에 해당한다.
- **진행률을 알 수 없을 때**: 모델이 진행률을 주지 않으면 줄무늬로 움직이는 바와 "경과 1:12"만 보여 준다. 남은 시간은 숨긴다.

### 2-3. Claude 사용량 표시와 경고

- **근거**: `board.md` 대표 결정(2026-11-21, 11-22). 월 상한은 **기본값을 비워 둔다**. 비어 있으면 사용량만 표시한다. 50% 단계는 두지 않는다.
- **상단 미터**: 누르면 기록 화면 ⑤의 사용량 카드로 이동한다.
  - 상한이 비어 있으면 "✳ Claude $0.12"처럼 금액만 보인다.
  - 상한을 입력하면 "✳ Claude 12%"와 작은 막대가 보인다.
- **상한 입력**: 기록 화면 사용량 카드의 "월 상한(선택)" 칸에서 한다. 비우면 다시 표시만 하는 상태로 돌아간다.

| 단계(`usage`) | 조건 | 미터 | 화면 |
|---|---|---|---|
| `none` | 상한 비어 있음(기본) | 금액만, 기본색 | 사용량 카드에 금액과 기능별 내역. 경고 없음 |
| `ok` | 상한 입력, 80% 미만 | % + 막대, 기본색 | 사용량 카드 막대(80% 눈금) |
| `warn` | 80~99% | 경고색 | Claude 버튼의 예상 비용 칩을 경고색으로. 상단에 닫을 수 있는 배너를 하루 1회 띄운다 |
| `over` | 100% 이상 | 위험색 | **✳ 버튼만** 비활성화하고 사유를 표시한다("정해 둔 Claude 상한에 닿았어요"). **로컬 기능(🖥)은 그대로 쓸 수 있다** |

- **비용 미리 보기**: 모든 ✳ 버튼 옆에 예상 비용 칩을 둔다(예: "약 $0.01"). 1단계에서 관찰한 '누르기 전에 비용 표시' 원칙이다.
- 시안의 금액 예시: 이번 달 $0.12(board 기준 월 약 170원), 상한을 입력한 예시는 $1.00이다.

### 2-4. 상태 공통 규칙

- **빈 상태**: 아이콘, 한 줄 설명, 주 행동 버튼 1개.
- **처리 중**: 작업 카드를 보여 주고 입력을 잠근다. 단 텍스트 편집은 허용한다(다음 작업 준비).
- **오류**: 원인 한 줄, 조치 버튼, 입력값 보존. 녹음과 파일은 절대 버리지 않는다.
- **접근성**
  - 진행률과 토스트는 `aria-live="polite"`, 오류는 `role="alert"`로 둔다.
  - 모든 조작을 키보드로 할 수 있어야 한다.
  - 색만으로 상태를 구분하지 않는다(아이콘과 문구를 함께 쓴다).

## 3. 화면별 설계

### ① 음성 만들기 (S1 내레이션 · ✳ + 🖥)

```
┌ 대본 ───────────────────────────────────────┐ ┌ 설정 ───────────────┐
│ [텍스트 입력, 큰 영역]                          │ │ 음성                 │
│                                              │ │  ○ 기본 1 여성 차분   │
│                                              │ │  ○ 기본 2 남성 또렷   │
│                                              │ │  ● 내 목소리 [복제]   │
│ 412자 · 예상 길이 1:05                         │ │ 속도  0.8 ━━●━━ 1.2  │
│ [✳ Claude로 대본 다듬기 ▾ 약 $0.01]            │ │ 형식  (MP3)(WAV)     │
└──────────────────────────────────────────────┘ └─────────────────────┘
하단 액션 바:  예상 처리 시간 약 1분 [실측 후]      [🖥 음성 만들기]
결과 카드: [▶ 파형 ─────── 1:05] [AI 생성][복제 음성]  [저장 폴더 열기][다운로드][설명란 문구 복사]
```

- **'대본 다듬기' 옵션 팝오버**
  - 목적: 홍보 영상 / 홈페이지 / 안내 멘트
  - 길이: 30초 / 1분 / 2분
  - 말투: 차분 / 밝게 / 정중
  - 체크박스 "숫자·영문·상호를 한글 읽기로"(기본 켬)
  - 결과는 **바꾸기 전/후 비교**로 보여 주고 [적용] [취소]를 둔다. 원문을 덮어쓰지 않는다.

| 상태 | 화면 |
|---|---|
| 빈 상태 | 입력창 안내 "영상에 들어갈 문장을 적거나, 주제만 적고 'Claude로 대본 다듬기'를 눌러 보세요". 음성 만들기 버튼은 비활성 |
| 대본 다듬는 중(✳) | 입력창 위에 얇은 진행 줄과 "Claude가 대본을 다듬는 중". 보통 수 초 걸린다 |
| 다듬기 비교 | 두 칸 비교(원문 / 제안), 바뀐 부분 강조, [적용] [취소] |
| 처리 중(🖥) | 결과 자리에 작업 카드. 대기 중이면 순번을 보여 준다 |
| 완료 | 결과 카드(플레이어, 배지, 저장·다운로드·문구 복사). 이전 결과는 아래로 쌓고 최근 3개까지 보인다 |
| 오류 | 결과 자리에 오류 카드. 원인 예: "음성 모델을 불러오지 못했어요", "대본이 너무 길어요(최대 ○자, 실측 후)". [다시 시도]를 두고 대본은 유지한다 |
| Claude 한도 100% | 다듬기 버튼 비활성과 사유 표시. 음성 만들기는 정상 |

### ② 받아쓰기 (S2 · 🖥 전사 + ✳ 요약·번역)

```
[빈 상태: 드롭존 "녹음 파일을 끌어다 놓으세요" · 형식·용량 안내]
──── 파일이 있을 때 ────
파일 줄:  회의_1121.m4a · 48:12 · [다른 파일]
┌ 탭: [전사문] [요약 ✳] [자막 SRT] [번역 ✳] ──────────┐ ┌ 내보내기·작업 ────────┐
│ 00:00:03  안녕하세요, 오늘 회의는 …   (편집 가능)       │ │ [✳ 요약 만들기 약 $0.02]│
│ 00:00:15  첫 번째 안건은 …                            │ │ [SRT 내보내기] [TXT]   │
│ …                                                   │ │ 번역 언어 [영어 ▾]      │
│                                                     │ │ [✳ 자막 번역 약 $0.03] │
└────────────────────────────────────────────────────┘ └──────────────────────┘
```

| 상태 | 화면 |
|---|---|
| 빈 상태 | 드롭존과 [파일 고르기]. 안내 "회의·통화·인터뷰 녹음(mp3, m4a, wav)". 최근 받아쓰기 3개 바로가기 |
| 처리 중(🖥) | 파일 줄과 작업 카드. 긴 작업이므로 문구 "창을 닫지 않으면 다른 화면을 써도 돼요. 끝나면 알려 드릴게요". 전사가 조각으로 나오면 끝난 부분부터 보여 준다(모델이 지원할 때만, 실측 후) |
| 완료 | 전사문 탭. 줄마다 타임스탬프를 누르면 그 지점부터 재생한다. 하단에 작은 고정 플레이어 |
| 요약 중 / 번역 중(✳) | 해당 탭에 진행 줄. 다른 탭은 쓸 수 있다 |
| 요약 결과 | 세 칸: 요약 / 결정 사항 / 할 일(체크 목록). [복사] |
| 오류 | 형식: "읽을 수 없는 파일이에요(mp3·m4a·wav)". 전사 실패: "받아쓰기 중 멈췄어요 → 다시 시도". 파일은 유지한다 |

### ③ 보고서 브리핑 (S3 · ✳ 요약 → 🖥 음성)

세 단계를 한 화면 세로 흐름으로 둔다. 단계 표시: ① 보고서 → ② 요약 확인 → ③ 음성.

```
① 보고서  [붙여넣기 영역] 또는 [파일(.txt .md .docx .pdf)]   글자 수
   브리핑 길이 (1분)(3분)(5분)   말투: 사장님께 드리는 존댓말(고정)
   [✳ 쉬운 말로 요약 약 $0.01]
② 요약 확인  [요약문 편집 가능 · 예상 길이 0:58]   [다시 요약]
③ 음성  음성 [기본 1 ▾] 속도 [1.0]   [🖥 브리핑 음성 만들기]
   결과 카드(① 화면과 같은 컴포넌트)
```

| 상태 | 화면 |
|---|---|
| 빈 상태 | ① 단계만 활성. ②③은 흐리게 잠기고 "보고서를 넣으면 열려요" |
| 요약 중(✳) | ② 자리에 진행 줄 |
| 요약 확인 | ②에서 편집할 수 있고 ③이 활성 |
| 처리 중(🖥) | ③ 아래 작업 카드 |
| 완료 | 결과 카드와 배지 |
| 오류 | 파일 읽기 실패: "이 파일에서 글을 꺼내지 못했어요. 내용을 붙여넣어 주세요". Claude 실패나 한도 초과 시 ②에 사유를 보이고 "요약 없이 원문으로 음성 만들기" 대체 경로를 둔다 |

### ④ 목소리 복제 (S4 · 🖥, 기획 §3의 1~7단계)

상단에 단계 표시를 둔다: 1 주인 확인 → 2 동의 낭독 → 3 샘플 → 4 이름·저장 → 5 미리듣기. 아래에 '내 목소리' 목록이 있다.

```
1 주인 확인   (● 본인(대표)) (○ 다른 사람 → 동의 낭독 + 동의서 파일 둘 다 필요)
2 동의 낭독   ┌ 낭독 문장 카드 ───────────────────────────────┐
              │ "나 ○○○는 2026년 11월 21일, 사내 음성 도구에서     │
              │  내 목소리를 복제해 영상 내레이션에 쓰는 데 동의합니다." │
              └──────────────────────────────────────────┘
              [● 녹음] → 녹음 패널(S1~S4 재사용)   ※ 문장은 매번 새로 만든다
3 샘플        드롭존 + [바로 녹음] · 샘플 목록 · 총 길이 링(10초 최소 · 3분 최대 · 1~2분 권장)
4 이름·저장   이름 [대표 목소리]  [🖥 복제 만들기] — 동의 기록이 없으면 비활성
5 미리듣기    [▶ 예시 문장] [음성 만들기에서 쓰기]
```

## 5. 프론트팀(03)과 맞출 것

- **상태 이름**
  - 녹음은 S0~S6(1단계 3-6)을 쓴다.
  - 작업은 `queued`(대기 중) / `preparing`(준비 중) / `running`(처리 중) / `done`(완료) / `failed`(실패) / `canceled`(취소됨)이다.
  - 사용량 단계는 `none`(상한 비어 있음·기본) / `ok` / `warn`(80%) / `over`(100%) 네 가지다. 50% 단계는 없다.
- **진행률**: 모델이 진행률을 주지 않으면 `progress=null`로 넘긴다. 그러면 줄무늬 바와 경과 시간만 보인다.
- **컴포넌트 단위(시안 클래스명과 같게)**: `app-shell`, `job-card`, `job-drawer`, `usage-meter`, `ai-badge`, `result-card`, `dropzone`, `rec-panel`, `stepper`, `seg`(세그먼트), `toast`.
- **시안 사용법**: `index.html`을 브라우저로 열면 된다.
  - 왼쪽 메뉴로 화면을 바꾼다.
  - 화면 오른쪽 위 '상태' 스위치로 빈 상태 / 처리 중 / 완료 / 오류를 바꿔 본다.
  - 상단 사용량 미터를 누르면 경고 단계가 순환한다.

## 6. 확인 못 함 · 대표가 정할 것

- 처리 시간, 최대 글자 수, 진행률 제공 여부는 DevOps 실측 전이다. 시안의 숫자는 자리표시다.

- 기본 한국어 음성의 이름과 개수(2~4개)는 백엔드 모델이 정해지면 바꾼다.
