## 1. 요약 (대표용)

1. **크레딧 하나로 모든 기능을 과금한다.** 월 크레딧 풀 하나에서 TTS, STT, 뮤직, 효과음, 더빙 등이 모두 빠진다. 기능마다 차감 단위가 다르다(글자, 분, 생성 횟수). [문서]
2. **UI와 API의 과금 체계가 다르다.** 웹 앱(Creative)은 크레딧으로 차감한다(TTS 1자 = 1크레딧). API는 달러 단가로 계산한다(TTS v4 $0.08/1천 자). 플랜에 포함된 API 사용량은 "플랜 가격 ÷ 단가"와 정확히 일치한다. [문서·계산]
3. **크레딧 1,000개의 값은 플랜마다 다르다.** Free 초과분은 $0.36, Starter $0.20, Creator $0.18, Pro 이상 $0.17이다. 이 값이 TTS 화면의 "추가 분" 단가와 같다. 비싼 플랜일수록 크레딧이 싸지는 구조다. [앱·계산]
4. **초과 사용은 선불 충전(PAYG)으로만 된다.** 구독 크레딧을 먼저 쓰고 충전 잔액은 그다음에 쓴다. 잔액이 0이 되면 서비스가 즉시 멈추고, 후불 초과 과금은 없다. 옛 "사용량 기반 후불"은 레거시 플랜과 Enterprise에만 남아 있다. [문서]
5. **이월 상한이 있다.** 쓰지 않은 크레딧은 월 한도의 2배까지 이월되고, 보유 상한은 월 한도의 3배다. Free는 이월이 없다. 다운그레이드나 해지 때 남은 구독 크레딧은 사라진다. 충전 크레딧은 12개월 뒤 만료된다. [문서]
6. **"생성 때 차감, 다운로드 때는 무료"가 원칙이다.** 품질 불만을 줄이는 장치로 무료 재생성(TTS·Studio 2회), v3의 "1회 과금에 결과 2개", 더빙 실패 시 환불이 있다. [문서]
7. **앱에는 개발자용 사용량 분석이 있다.** "MCP 및 API > 모니터링" 화면에서 크레딧 사용량, 요청 수, 성공률, 지연, 동시 요청, 웹훅, 요청 로그를 16개 기준으로 그룹화하고 CSV로 내보낼 수 있다. 같은 데이터를 API로도 조회할 수 있다. [앱·문서]
8. **기획팀 물량안 검증 결과(§5)**: 기본안(MAU 5,000)은 월 약 2,854만 크레딧, TTS로 환산하면 월 1,712만 자 규모다. DevOps 가정(TTS 월 1,000만 자)과 같은 규모다. 단, 이 가정에서는 **크레딧 소비의 40~59%가 무료 사용자**다. 무료 한도 설계가 원가를 좌우한다.
9. **원화 단가안과 손익분기(§9, 포지셔닝 B, 1크레딧 = 0.1원 고정, v4: DevOps 안 B 고정비 반영)**
   - 단가안: 고품질 TTS 100원/1천 자, 저지연 TTS 50원/1천 자, STT 4.5원/분, 음성 에이전트 75원/분.
   - **B2B 물량(08 §5) + DevOps 고정비(06 §4.9, v4)**
     - 12개월 기본안은 모든 리전에서 흑자다(월 +1,288만~+3,936만 원).
     - 3개월 기본안은 리전이 가른다: 전부 해외 +1,060만, 혼합(DevOps 권고) −81만, 전부 한국 −457만 원. 실시간 GPU에 99% 피크 여유와 예비 1장을 둔 C안 기준이다.
     - 실시간 GPU를 1장(A안, SLA 낮춤)으로 하면 3개월 기본안은 +507만 / +883만 / +1,272만 원으로 모두 흑자다. **SLA 수준(대표 결정 대기)이 한국·혼합 리전의 흑자 여부를 뒤집는다**(§9-5 (2-1)).
     - AICC 중견 1곳의 월 공헌이익은 약 1,037만 원이다.
   - 소비자형(MAU) 경로는 해외 이중화에서 GPU를 3장으로 늘려야 해서 MAU 약 2만 9천이 필요하다. 한국 A100이면 성립하지 않는다.
   - 결론은 공개 근거 없는 B2B 1곳당 물량 추정에 기대고 있다. **AICC 인터뷰로 확인하기 전에는 투자 판단 근거로 쓰지 않는다.** 인건비·LLM·영업비용은 빠져 있다.

## 5. 기획팀 물량 가정 검증 (대표 추가 지시)

### 5-1. 기획팀 질문 (a): 차감 규칙 확인 결과
- TTS 1자 = 1크레딧: **맞다**(웹 기준, 모든 모델). 한글은 1음절이 1자다. API는 달러 단가이고 Flash·Turbo는 절반이다.
- STT 330/분(Free만 12분 예외), 효과음 200/회(앱 표시 66~68과 불일치, 실행 확인 필요), 뮤직 ~900/분 × 변형 수, 보이스 체인저·아이솔레이터 1,000/분, 자동 더빙 2,000·3,000/분(v2 약 13,500 계산값).
- 클로닝은 **크레딧을 쓰지 않는다**. 대신 "음성 추가·편집 횟수"(55/65/95/290)와 "음성 슬롯"(3/10/30/160) 두 한도로 제한한다. IVC는 Starter부터, PVC는 Creator부터 가능하다. 클로닝한 음성으로 생성할 때는 일반 TTS처럼 글자당 차감된다. 클로닝 자체가 무료인지는 문서 근거가 없어 확인 못 함이다. 실행 확인 필요.
- 기획팀이 적은 한도 숫자(10k/30k/121k/600k, TTS ~10/30/121/600분, 슬롯 3/10/30/160, 작업 55/65/95/290)는 **모두 일치한다**.

### 5-2. 구조 보완 제안
기획팀 식 "MAU × 요금제 구성비 × 월 한도 × 소진율"은 **월 총 크레딧**까지만 나온다. 기능별 사용량을 얻으려면 두 단계가 더 필요하다.

> 월 총 크레딧 = 무료 사용자 × 10,000 × 무료 소진율 + Σ(유료 사용자 × 플랜 구성비 × 플랜 크레딧) × 유료 소진율
> 기능별 월 사용량 = 월 총 크레딧 × **기능별 크레딧 비중** ÷ **기능별 크레딧 단가(§3)**

- 유료 사용자 안의 플랜 구성비가 비어 있다. → [가정] Starter 60% / Creator 30% / Pro 10%. 유료 1인 평균 월 114,300크레딧, 평균 구독료 $20.10이다.
- 기능별 크레딧 비중도 필요하다. → [가정] TTS 60%, STT 10%, 뮤직 8%, 효과음 5%, 보이스 체인저·아이솔레이터 7%, 더빙(v1 워터마크) 10%.
- 에이전트(통화 분)는 크레딧 비중과 따로 잡는 것이 낫다. 단가가 분당 달러이고 LLM 비용이 붙어서 원가 구조가 다르다.
- MAU 3안, 전환율, 소진율에 대해 데이터팀이 가진 다른 근거는 **없다**. 시장 근거를 확인 못 했으므로 "[가정]" 표기를 유지한다.

**해석**

### 6-4. 계량(metering) 설계 원칙 [제안]
1. **분석 이벤트와 과금 원장을 분리한다.** 과금은 서버 원장(`credit_ledger`)이 정본이다. 기록 단위는 `entry_type`(grant/rollover/consume/refund/topup/expire/adjust), `amount`, `balance_after`, `request_id`, `feature`, `model_id`, `voice_id`, `api_key_id`, `surface`다. 분석 이벤트는 `request_id`로 원장과 연결만 한다. ElevenLabs의 기록 항목도 차감 전후 값(`character_count_change_from/to`)을 담고 있다.
2. 사용량 분석 화면과 API가 같은 원장을 기준으로 여러 축(제품, 모델, 음성, 사용자, 키, 표면)으로 집계하게 한다(§4-2 구조).
3. 생성 전에 예상 크레딧을 보여 주고, 생성할 때 차감하고, 실패하면 자동으로 환불한다. 무료 재생성 정책(횟수, 유효 시간, 조건)은 원장에서 `is_free_regen`으로 남긴다.
4. **[대표 잠정 결정 2026-11-21] 크레딧 1개의 원화 가치는 모든 플랜에서 같게 고정한다.** 플랜 혜택은 보너스 크레딧과 기능·한도 차이로 준다. 따라서 ElevenLabs처럼 잔액을 달러로 보관하고 플랜을 바꿀 때 다시 환산하는 문제가 없다. 원장에는 크레딧 수만 기록한다. 단가안은 §9에 있다.
5. 이월 상한과 소멸 규칙, 충전 크레딧 만료(12개월)는 회계(선수 수익) 처리와 같이 정한다.

### 9-3. 해석

1. **P0만으로는 기획 물량 기본안이 어느 구성에서도 적자다.** 가장 싼 해외 최소 구성도 월 −95만 원이다. 흑자는 낙관안을 해외 구성에 올렸을 때뿐이다(+228만~+334만 원).
2. **리전 선택이 손익분기를 4배 바꾼다.** 기본 전환율 기준으로 한국 이중화는 MAU 약 8만, 해외 이중화는 약 2만 1천이 필요하다. 개인정보 국외 이전이 허용되는지(06 §4.3, 법무 확인 필요)가 사업성 판단의 첫 번째 변수다.
3. **소비자형 사용량으로는 여전히 B가 성립하기 어렵다.** 유료 1인 월 종량 매출은 약 2,600원(기본안)이다. B2B 물량으로 보면 다음과 같다.
   - 해외 이중화 기준으로 고품질 TTS 월 2,730만 자.
   - 에이전트는 해외 구성이면 월 1만 7천 분이 추가 GPU 손익분기다.
   - **AICC 고객 1곳의 월 물량(마케팅 인터뷰 대기)이 들어오면 "필요 고객 수"로 바로 환산한다.**
4. **ElevenLabs API를 사서 되파는 방식은 역마진이다.** 원가가 저지연 53.2원, 고품질 106.5원으로 판매가(50원, 100원)보다 높다. 06 §4.4는 "초기에는 API로 시작하고 물량이 커지면 직접 운영으로 전환"하는 안을 언급한다. 이 안을 쓰려면 초기 단가를 원가 위로 올리거나, 초기 손실을 감수한다는 결정이 필요하다(대표 결정 사항).
5. **변동비 비중이 3%(에이전트는 18%)라서**, 가격을 낮추면 필요 물량이 거의 같은 비율로 늘어난다. 할인 여지는 고정비를 회수한 뒤에 쓰는 게 맞다.

### 9-5. v3 — GPU 대수 반영 + B2B 물량(마케팅 08 §5) [계산] (2026-11-22)

- **입력**
  - DevOps 06 §4.8의 GPU 용량 규칙을 그대로 옮겼다: 피크 = 평균 + 2.33√평균, GPU 1장당 동시 생성 3.5, 하루 12시간 활성, RTF 0.1228(가장 느린 값), 한국어 350자/분.
