## 1. 확정 시나리오 (사용자 답변 2026-11-21)

| # | 시나리오 | 흐름 | 처리 위치 |
|---|---|---|---|
| S1 | 고객 홍보 영상·홈페이지 영상의 **한국어 내레이션** | 대본 작성·다듬기 → 음성 생성 → AI 표시 포함 저장 | 대본: Claude / 음성: 로컬 |
| S2 | 회의·통화·인터뷰 **녹음 받아쓰기 → 요약 → 자막(SRT) → 외국어 자막 번역** | 업로드 → 전사 → 요약·자막 → 번역 | 전사: 로컬 / 요약·번역: Claude |
| S3 | 사장님께 드리는 **보고서를 음성 브리핑**으로 | 보고서(텍스트·파일) → 쉬운 말 요약 → 음성 | 요약: Claude / 음성: 로컬 |
| S4 | **대표 본인 목소리 복제**로 내레이션·안내 멘트 | 본인 동의 낭독 → 샘플 → 즉시 복제(IVC) → 음성 생성 | 음성: 로컬(CPU, 느릴 수 있음) |

- 처음 제안한 S5(자막·번역)는 S2에 합쳐졌다.
- 확정된 운영 조건
  - 사용자 1명, 이 PC의 브라우저 화면이다. 로그인·다중 계정·권한·동시 처리는 만들지 않는다. 서버는 이 PC 안에서만 열리게(localhost) 한다[제안].
  - Claude API는 보유 크레딧 안에서만 쓴다. 기본 모델은 Haiku다. 같은 지시문(시스템 프롬프트)은 캐싱한다.
  - **월 상한(대표 결정 2026-11-22)**: 강제 상한은 없다. 누적 사용량만 표시한다.
  - 상한 금액 칸은 비워 두고, 사용자가 입력하면 80%에서 경고하고 100%에서 Claude 기능을 멈춘다.
  - 결과물은 외부에 공개한다. 모든 생성 음성에 AI 생성 표시를 하고, 복제는 동의 기록이 있는 목소리만 허용한다.

## 3. 목소리 복제(S4) 흐름과 동의 규칙 (P0)

기능 지도 §3(ElevenLabs IVC·PVC 흐름)을 사내 1인 기준으로 줄였다. ElevenLabs IVC는 체크박스 동의만 받는다. 우리는 외부 공개를 전제로 하므로 **동의 낭독 기록**을 필수로 둔다.

| 단계 | 화면·행동 | 처리 | 규칙 |
|---|---|---|---|
| 1 | '목소리 복제' → 이 목소리의 주인 확인: "본인(대표)" / "다른 사람" | 없음 | "다른 사람"을 고르면 그 사람의 동의 낭독 녹음과 동의서 파일을 둘 다 올려야 다음으로 넘어간다. 기본은 대표 본인만 |
| 2 | **동의 낭독**: 화면에 날짜·목적이 들어간 문장(예: "나 ○○는 2026년 ○월 ○일 내 목소리 복제에 동의합니다")을 띄우고 마이크로 녹음 | 없음(녹음 저장) | 문장은 매번 새로 만든다(재사용 방지). 녹음 파일과 시각을 동의 기록으로 보관 |
| 3 | 샘플 올리기(파일 업로드 또는 바로 녹음) | 없음 | 10초~3분, 파일당 10MB(ElevenLabs 기준 준용). 1~2분 권장 안내. 길이 진행 표시 |
| 4 | (선택) 소음 제거 | 로컬 | P1이 들어오기 전에는 "조용한 곳에서 녹음" 안내만 |
| 5 | 이름 붙이고 저장 | 로컬(복제 처리) | 처리 시간 표시 **[실측 후]**. 동의 기록이 없으면 저장 불가 |
| 6 | 미리듣기 → TTS 음성 목록에 '내 목소리'로 추가 | 로컬 | 이 음성으로 만든 파일에는 AI 표시와 '복제 음성' 로그를 남긴다 |
| 7 | 삭제 | 없음 | 복제 음성·샘플은 즉시 삭제한다. **동의 기록은 목소리가 있는 동안 보관하고, 목소리를 지운 날부터 1년 뒤 자동 삭제한다**(대표 결정 2026-11-22). 기록 화면에 삭제 예정일을 표시한다 |

- 동의 낭독이 실제 샘플 목소리와 같은 사람인지 자동으로 대조하는 기능(성문 비교)은 만들지 않는다. 사용자가 1명이고, 성문 비교는 민감정보 처리 부담이 있다(마케팅 08 §3-4). 대신 동의 녹음을 보관해 사후 확인할 수 있게 한다[제안].

## 4. DevOps CPU 실측 후 P0 조정 규칙

- 측정 방식(DevOps 회신 2026-11-22): 계획은 `06-devops/work/voice-bench/PLAN.md`, 결과는 `06-devops-cpu-bench.md`로 받는다.
  - STT 1시간 값은 30초·5분 실측을 환산한다.
  - 품질은 공개 한국어 음성과 TTS 생성음으로만 잰다. 실사용과 다를 수 있으므로 **최종 품질 판단은 대표 청취 확인**으로 한다.
- 기준 숫자는 기획팀 제안이다.

| 실측 항목 | P0 유지 기준 | 기준 미달 시 |
|---|---|---|
| TTS 속도(음성 1분을 만드는 시간) | 1분 이하 | 2분 이하면 "기다리는 작업"(진행 표시)으로 유지. 그보다 느리면 더 가벼운 모델로 교체 |
| TTS 품질(대표 청취) | 외부 공개 영상에 쓸 만함 | S1은 보류하고 S3(브리핑)만 P0 |
| STT 속도(1시간 녹음) | 30분 이하 | 1시간 이하면 "걸어 두고 나중에 받기"로 유지 |
| STT 정확도 | 요약·자막에 쓸 만함(대표 판단) | 소음 제거를 P0로 올리거나 더 큰 모델 + 느린 처리 |
| 메모리 | TTS·STT·복제 모델을 함께 띄워도 15.5GB 안 | 한 번에 하나만 실행(작업 대기열) |
| IVC 속도(복제 음성으로 한 문장) | 30초 이하 | 2분 이하면 "기다리는 작업"으로 P0 유지(대표가 느려도 쓴다고 답함). 그보다 느리면 S4는 P1로 내리고 GPU 확보 시 재개 |
| IVC 품질(유사도, 대표 청취) | 본인 목소리로 들림 | P1로 내리고 기본 음성으로 대체 |

## 5. 디자인·프론트엔드에 넘길 화면 범위 (P0)

브라우저 한 화면 앱이다. 왼쪽 메뉴 5개를 둔다. 로그인 화면은 없다.

| 화면 | 들어갈 것 | 처리 위치 |
|---|---|---|
| ① 음성 만들기 | 대본 입력창, 'Claude로 대본 다듬기' 버튼, 음성 선택(기본 + 내 목소리), 속도, 생성·진행 표시, 미리듣기·저장 | Claude + 로컬 |
| ② 받아쓰기 | 파일 올리기, 진행 표시, 전사문(타임스탬프), 버튼: 요약·SRT 내보내기·번역(언어 선택) | 로컬 + Claude |
| ③ 보고서 브리핑 | 보고서 붙여넣기·파일, 요약 길이, 요약문 확인·수정 → 음성 만들기 | Claude + 로컬 |
| ④ 목소리 복제 | §3의 1~7단계(동의 낭독 → 샘플 → 저장), 내 목소리 목록·삭제 | 로컬 |
| ⑤ 기록 | 날짜별 결과 목록(다시 듣기, 다운로드, 복제 음성 여부, AI 표시 상태), 이번 달 Claude 사용량 | 없음 |

- 공통 요소
  - 생성물마다 'AI 생성' 표시(파일 메타데이터와 화면 배지)를 붙인다.
  - CPU 처리가 느리므로 모든 생성에 진행률과 대기열을 보여 준다.
  - Claude 크레딧 상한에 가까워지면 경고한다.
