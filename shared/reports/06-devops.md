## [2026-11-21] 1단계 인프라 요구사항 분석 — 완료
모델·effort 검토: 현재 opus/high → 적정(설계·판단) · 가격 수집은 web-fetch 서브에이전트 2개로 처리

- **산출물**: `shared/research/elevenlabs/06-devops-infra.md`
- **확인한 핵심**: 저지연 TTS ~100ms(v4 Turbo, Flash v2.5, 서버측 중앙값), 실시간 STT ~150ms. 동시성은 플랜별 표대로이고, HTTP는 요청 단위로, TTS WebSocket은 "생성 중"에만 센다. 한도를 넘으면 거부하지 않고 저우선 큐로 보낸다(~50ms). WebSocket은 20초 비활성 시 종료, 연결당 컨텍스트 5개. 기본 데이터 보존, 백업 30일, 에이전트 대화 2년. ZRM은 Enterprise 전용이고 `enable_logging=false`로 켠다(클로닝·더빙·Studio는 대상 아님).
- **구성안**: Edge 게이트웨이 → stateful WebSocket 게이트웨이(CPU) → GPU 풀 2개(실시간 L4 상시 / 배치 L40S~A100 오토스케일). 저장소 R2, 작업 큐 Cloudflare Queues, DB Postgres(Supabase), SIP는 LiveKit SIP + Telnyx/Twilio 트렁크. ElevenLabs SIP Digest의 realm이 "LiveKit"이라 LiveKit 기반으로 추정했다.
- **월 비용(확인된 단가만)**: 직접 운영 약 $855 / $2,230 / $4,960(낮음/중간/높음). 같은 물량을 ElevenLabs API로 사면 약 $2,220~2,620 + LLM. 초기 물량에서는 직접 운영이 싸지 않다. LLM, CPU VM, 관측 비용은 단가를 확인 못 해 빠져 있다.
- **보안**: 키 범위(실제 scope 30여 개 목록 정리), 크레딧 한도, IP 허용목록, 만료, 1회용 토큰(15분), HMAC 웹훅 + 재시도 5회 + 자동 비활성화, OCSF 감사로그를 요구사항으로 정리했다.
- **막힌 점**: GPU 대수는 엔진 처리량을 몰라 [가정]으로 잡았다. 실측(TTFA, 동시성 헤더, 웹훅 서명 형식)은 크레딧이 차감되므로 "실행 확인 필요"로 남겼다. 앱 화면은 열지 않았다.
- **요청 사항**: 04 백엔드 → 엔진별 VRAM과 GPU당 실시간 스트림 수 · 01/07 → 초기 물량(자수, 시간, 분, 피크 동시 수) · 대표 → 한국 리전과 국내 전화번호 필요 여부, 엔터프라이즈 기능(ZRM, 레지던시, 감사로그)의 MVP 포함 여부
