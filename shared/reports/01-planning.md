  - 부록 A: 공식 문서 기반 기능별 상세(출처 URL 포함)
- **메뉴 지도**: 지시서의 22개 메뉴, '더 많은 도구' 4개, 에이전트 플랫폼 메뉴까지 크롬 새 탭에서 확인했다. 기능마다 하는 일·흐름·입력·한도·요금제 제한과 출처([앱] 경로 / [문서] URL)를 달았다. 작업 후 탭은 닫았다.
- **클로닝 상세**(§3): 즉시 복제와 프로페셔널 복제의 비교표, 단계별 흐름(업로드/녹음 → 검증 → 저장, 캡차 본인 확인 → 학습 대기열 → 상태 전이), 한도·요금제·API 대응을 정리했다.
  - 클로닝은 크레딧이 아니라 음성 슬롯 수와 월 작업 횟수로 제한된다.
- **MVP**(§5, 대표 결정 반영: 국내 우선, 안 B로 진입하고 안 A를 차별점으로)
  - P0: TTS·STT API, 한국어 음성·발음 사전, 원화 종량 계량·콘솔, 웹 체험 화면, 생성 로그·AI 고지

  - P2: PVC와 크리에이티브 기능 전반

- **지킨 것**: 생성·클로닝·녹음·업로드·결제·설정 변경은 하나도 실행하지 않았다.
