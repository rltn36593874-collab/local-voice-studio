## 대전제 규칙 (사용자 지정 · 모든 팀 공통, 2026-11-22)
1. **사진·이미지는 gemini.google.com 웹에서 만든다. 영상은 Google Flow 웹에서 만든다.** 다른 이미지·영상 생성 도구는 쓰지 않는다.

## ⛔ 2026-11-22 ElevenLabs 계정 사용 전면 중단 (법무 권고 채택)
로그인 계정으로 하는 관찰·생성·호출을 모두 금지한다. 승인 대기 중이던 ElevenLabs 생성 항목은 전부 취소한다. 기존 자료는 아이디어 수준으로만 쓰고, 화면·문구·API 경로는 복제하지 않는다. 외부 변호사 검토(기존 관찰의 위반 소지)는 중간 우선순위로 사용자 판단 대기.

판매하지 않는다. **사내 전용 도구**로 만든다. 음성은 자체 모델을 쓰고, LLM이 필요한 부분은 Claude API 크레딧으로 처리한다. 가격·손익·시장·SLA·리전 관련 결정과 승인 대기 항목은 모두 무효(보류)로 한다. 대표가 새 방향안을 사용자에게 올렸다.
