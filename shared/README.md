# 회사 공용 폴더

## 대전제 규칙 (사용자 지정 · 모든 팀 공통, 2026-11-22)
1. **사진·이미지는 gemini.google.com 웹에서 만든다. 영상은 Google Flow 웹에서 만든다.** 다른 이미지·영상 생성 도구는 쓰지 않는다.
2. **사용자가 다른 툴을 구독하기 전까지 이미지·영상 생성 API는 요청하지 않는다.** 생성은 위 두 웹 화면에서 사용자 계정으로만 한다.


- `directives/<팀ID>.md` — 대표가 각 팀에 내리는 지시서 (대표만 작성)
- `reports/<팀ID>.md` — 각 팀이 대표에게 올리는 보고서 (해당 팀만 작성, 최신 내용을 위에 추가)
- `board.md` — 전사 현황판 (대표가 관리)

팀 ID: `01-planning`(기획팀), `02-design`(디자인팀), `03-frontend`(프론트엔드 개발팀), `04-backend`(백엔드 개발팀), `05-qa`(QA팀), `06-devops`(인프라/DevOps팀), `07-data`(데이터/분석팀), `08-marketing`(마케팅/홍보팀), `09-legal`(법무팀)
