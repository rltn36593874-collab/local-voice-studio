# 디자인팀 지시서

## [2026-11-21] ElevenLabs UI/UX 구조 분석 (1단계)

**목표**: 같은 기능을 우리 디자인으로 만들기 위해 화면 구조와 인터랙션 패턴을 분석한다. 생김새를 베끼지 않고 구조와 상태만 정리한다.

**산출물**: `shared/research/elevenlabs/02-design-ux-analysis.md`
- 전체 레이아웃 패턴: 왼쪽 내비, 가운데 작업 영역, 오른쪽 설정·기록 패널, 상단 검색·알림
- 핵심 화면 정보구조: 음성 생성(복제 3종 + 리믹싱), 텍스트 음성 변환(화자 추가, 오디오 태그 입력, 모델·안정성·유사성·언어·오디오 효과·출력 형식), 보이스 체인저, 더빙, 스튜디오
- **녹음 UI의 상태 정의**: 업로드/녹음 선택 → 녹음 중 → 검토 → 제출 전까지 화면에 보이는 상태와 안내 문구 종류(녹음 버튼은 누르지 않는다. 볼 수 없는 상태는 '확인 못 함')
- 재사용 컴포넌트 목록(음성 선택기, 슬라이더, 오디오 플레이어, 파형, 업로드 영역, 모델 선택 시트 등)
- 우리 디자인 시스템 방향 제안 1안

**완료 기준**: 핵심 화면 5개 이상의 구조도, 컴포넌트 목록, 녹음 UI 상태표
**의존 팀**: 기획팀 기능 지도(병행 진행, 나중에 맞춘다)

## 공통 규칙 (전 팀)
- 이번 단계는 **분석·학습 단계**다. 아직 우리 제품을 만들지 않는다. 결과물은 문서다.
- 근거 자료
  1. ElevenLabs 앱: 사용자 크롬에 로그인돼 있다(`https://elevenlabs.io/app/home`, 한국어 UI). 반드시 **자기 탭을 새로 열어서** 보고, 끝나면 닫는다.
  2. 공식 문서: `https://elevenlabs.io/docs/llms.txt` (전체 색인), `https://elevenlabs.io/docs/openapi.json`
  3. 대표실 앱 관찰 메모: `shared/research/elevenlabs/00-ceo-app-notes.md`
- **금지 (사용자 계정 보호)**: 생성·변환 버튼 실행(크레딧 차감), 음성 클로닝 생성, 마이크 녹음 시작, 파일 업로드, 결제·구독·설정 변경, 비밀번호 입력. 꼭 실행해 봐야 하는 단계가 있으면 하지 말고 보고서에 "실행 확인 필요"로 적어 대표에게 올린다.
- 기능 로직만 파악한다. 브랜드명·문구·UI 그래픽·코드를 베끼지 않는다.
- 짐작 금지: 직접 확인한 것만 쓰고, 확인 못 한 것은 "확인 못 함"으로 적는다. 출처(URL 또는 앱 화면 경로)를 단다.
- 산출물은 `shared/research/elevenlabs/` 아래에 저장하고, 끝나면 `shared/reports/<팀ID>.md` 맨 위에 요약(5~10줄)과 파일 경로를 추가한다.
- 마감: **2026-11-22 (토) 18:00**

## [2026-11-21 사용자 방향 전환 — 즉시 적용] 판매 안 함, 사내 전용
- 사용자 결정: 이 제품은 **판매하지 않는다. 우리 회사만 쓰는 사내 도구다.** 음성 모델은 자체 모델을 쓰고, LLM이 필요한 부분은 Claude API 크레딧으로 처리하는 방향을 검토 중이다.
- 따라서 판매 관련 작업을 **모두 중단한다**: 가격·원화 단가·손익분기, B2B 물량, 시장·포지셔닝, SLA·리전 비용, 요금제·크레딧 판매 설계.
- 새 지시가 올 때까지 대기한다. 진행 중인 판매 관련 문서는 지금 상태로 두고 더 고치지 않는다.
