## [2026-11-21 사용자 방향 전환 — 즉시 적용] 판매 안 함, 사내 전용
- 사용자 결정: 이 제품은 **판매하지 않는다. 우리 회사만 쓰는 사내 도구다.** 음성 모델은 자체 모델을 쓰고, LLM이 필요한 부분은 Claude API 크레딧으로 처리하는 방향을 검토 중이다.
- 따라서 판매 관련 작업을 **모두 중단한다**: 가격·원화 단가·손익분기, B2B 물량, 시장·포지셔닝, SLA·리전 비용, 요금제·크레딧 판매 설계.
- 새 지시가 올 때까지 대기한다. 진행 중인 판매 관련 문서는 지금 상태로 두고 더 고치지 않는다.

## [2026-11-21] 2단계 — 사내 전용 · 이 PC(CPU) 기준 음성 엔진 선정
**전제(사용자 확정)**: 판매하지 않는 사내 도구다. 음성 모델은 이 PC(NVIDIA GPU 없음, Core Ultra 5 225, RAM 15.5GB)에서 CPU로 돌린다. 텍스트 처리(대본·번역·발음 정규화·에이전트 대화)는 Claude API를 쓴다. 비용은 0원을 목표로 한다.
**라이선스 원칙**: MIT·Apache 2.0 등 상업 이용이 명확히 허용되는 모델만 쓴다. 비상업(NC)·매출 기준 조항이 있으면 제외한다. 모델 가중치 라이선스와 코드 라이선스를 따로 확인한다.
**산출물**: `shared/research/elevenlabs/04-backend-cpu-engine-shortlist.md`
- 기능별 CPU 후보 1~3개와 라이선스(가중치/코드, 원문 URL), 한국어 지원, CPU 실행 가능 여부(공개 근거). 기능: STT, 한국어 TTS, 제로샷 음성 클로닝, 보이스 체인저, 음원 분리(보이스 아이솔레이터)
- DevOps가 바로 설치·측정할 수 있게 후보별 pip 패키지명, 모델 ID, 최소 실행 예시 코드 1개씩
- 끝나면 DevOps(06-devops-33)에 경로를 알린다.
**금지**: 설치는 DevOps가 한다(백엔드는 설치하지 않는다). ElevenLabs API 호출 금지.
