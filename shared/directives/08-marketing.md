## [2026-11-21 사용자 방향 전환 — 즉시 적용] 판매 안 함, 사내 전용
- 사용자 결정: 이 제품은 **판매하지 않는다. 우리 회사만 쓰는 사내 도구다.** 음성 모델은 자체 모델을 쓰고, LLM이 필요한 부분은 Claude API 크레딧으로 처리하는 방향을 검토 중이다.
- 따라서 판매 관련 작업을 **모두 중단한다**: 가격·원화 단가·손익분기, B2B 물량, 시장·포지셔닝, SLA·리전 비용, 요금제·크레딧 판매 설계.
- 새 지시가 올 때까지 대기한다. 진행 중인 판매 관련 문서는 지금 상태로 두고 더 고치지 않는다.

## [2026-11-22] 새 과업 — 디랙스 마이마운틴 MM5050SE 홍보 영상 (15~20초)
**대전제**: 이미지는 gemini.google.com 웹, 영상은 Google Flow 웹에서만 만든다. 이미지·영상 생성 API는 쓰지 않는다(shared/README.md 맨 위).
**목표**: 짐링크에서 파는 "디랙스 마이마운틴 MM5050SE"의 15~20초 홍보 영상. 대본과 영상 구도는 사용자 아이디어를 듣고 정한다(대화 창구는 대표). 마케팅팀은 자료 조사, 초안, Flow용 프롬프트 작성을 맡는다.
**1단계 (지금)**: `shared/research/mm5050se/08-product-brief.md`
- 짐링크 상품 페이지에서 제품 사실 확인: 정확한 제품명, 종류, 핵심 기능·사양, 크기, 가격, 대표 사진·영상 유무, 내세우는 장점 문구. 출처 URL을 단다. 확인 못 한 것은 "확인 못 함"으로 쓴다.
- 짐링크와 디랙스 브랜드 톤(색, 말투)
- 15~20초 홍보 영상 방향 초안 2~3개(타깃, 핵심 메시지 1개, 장면 3~4컷 흐름). 사용자 아이디어를 받기 위한 질문 3~5개
- 사이트는 읽기만 한다. 로그인, 장바구니, 구매, 문의 작성은 금지다.
**2단계 (사용자 확정 후)**: 대본 확정 → 컷별 Flow 프롬프트(영문 + 한글 설명) → 사용자 승인 후 Flow에서 생성
**마감**: 1단계 결과는 오늘 안에, 가능한 한 빨리

## [2026-11-22] MM5050SE 영상 2단계 — 사용자 답변 확정, 대본·프롬프트 작성
**사용자 확정**
1. 방향: **C안(센터·헬스장 납품형)**
2. 비율: **세로 9:16**
3. 출연: **사람과 기계 둘 다**. 사람은 **50대 여성**
4. 배경: **헬스장**
5. 소리: **내레이션 + 자막 + 음악** 모두
6. 마지막 화면: **짐링크 로고 + 전화 010-2760-3659 + "DM 견적 문의"** 모두
7. 분위기: **밝고 경쾌**
8. 마지막 장면: **산 정상처럼** 화면이 열리는 연출
9. **"음성과 음악은 대충 찍어내지 말고 한 번 만들 때 제대로"** → 컷마다 목소리·음악이 바뀌거나 끊기지 않게 설계한다.

**문구 규칙(법무 09-legal-claims.md)**: "최저가 100% 보장" 금지. "1/2 면적", "2배 칼로리"는 대체 문구만 쓴다. "제조본사 공식 판매처"는 증빙 확인 전까지 "디랙스 정품 판매·설치"로 쓴다. 사양(최대 50% 경사, 2HP, 130kg)은 써도 된다.

**산출물**: `shared/research/mm5050se/08-script-and-prompts.md`
- 먼저 Flow 기능 확인: 사용자 크롬(로그인된 계정)에서 Flow 화면을 **보기만** 하고 확인한다. 생성 버튼은 누르지 않는다. 확인할 것은 클립 길이, 세로 9:16 지원, 음성·대사·음악 생성 여부, 참고 이미지(재료·프레임) 기능, 이어 붙이기(extend·scene builder)로 목소리·음악을 이어 가는 방법, 크레딧 소모다. 확인 못 한 것은 "확인 못 함"으로 쓴다.
- 대본: 15~20초 타임라인(초 단위), 컷별 화면 묘사, 한국어 내레이션(글자 수를 시간에 맞춤), 화면 자막, 음악 방향(BPM·악기·분위기), 마지막 엔드카드 구성
- 음성·음악 연속성 계획: Flow 기능 확인 결과에 맞춰 목소리·음악이 컷 사이에서 튀지 않게 만드는 방법(예: 하나의 연속 생성 + extend, 같은 음성 묘사를 고정, 엔드카드 처리 방식). 대안과 장단점을 쓴다.
- 컷별 Flow 프롬프트(영문 + 한글 설명). 제품 외형이 MM5050SE와 같아야 하니 참고 이미지 사용 방법을 함께 쓴다.
- 엔드카드: 로고는 실제 짐링크 로고 파일이 필요하다. 이미지가 필요하면 gemini.google.com에서 만든다(대전제).
**금지**: 생성은 사용자 승인 전까지 하지 않는다. 이미지·영상 API는 쓰지 않는다. 파일 다운로드는 대표 승인 뒤에 한다.
**보고**: 끝나면 대표에게 요약 보고(사용자에게 보여 줄 대본표 포함)
