# 기획팀 지시서

## [2026-11-21] ElevenLabs 전 기능 분석 (1단계)

**목표**: 회사 목표는 ElevenLabs의 기능 전부를 우리 제품으로 만드는 것이다. 기획팀은 전체 기능 지도와 화면별 사용자 흐름을 정리하고, 개발 우선순위안을 낸다.

**산출물**: `shared/research/elevenlabs/01-planning-feature-map.md`
- 앱 왼쪽 메뉴 전부의 기능 지도: 홈, 음성(보이스 라이브러리), 스튜디오, 흐름, Producer, 앱, 자산, 텍스트 음성 변환, 음성 생성(즉시 음성 복제·프로페셔널 음성 복제·보이스 디자인·음성 리믹싱), 효과음, 이미지 및 비디오, 보이스 아이솔레이터, 보이스 체인저, 뮤직, 음성 텍스트 변환, 더빙, 오디오북, 더 많은 도구, 에이전트, MCP 및 API, 구독
- 기능마다: 하는 일, 사용자 흐름(단계별), 입력·설정 항목, 한도(길이·용량·개수), 요금제 제한(업그레이드 요구 여부)
- **음성 녹음·클로닝 흐름을 가장 자세히**: 즉시 복제(업로드/녹음, 10초~3분, 파일당 10MB) vs 프로페셔널 복제(10분~2시간, 본인 확인, 학습 대기)의 전 단계
- MVP 우선순위안(P0/P1/P2)과 이유

**완료 기준**: 메뉴 누락 없음, 기능마다 출처 표기, 우선순위안 포함
**의존 팀**: 없음(선행). 디자인·개발팀이 이 문서를 참고한다.

## 공통 규칙 (전 팀)
- 이번 단계는 **분석·학습 단계**다. 아직 우리 제품을 만들지 않는다. 결과물은 문서다.
- 근거 자료
  1. ElevenLabs 앱: 사용자 크롬에 로그인돼 있다(`https://elevenlabs.io/app/home`, 한국어 UI). 반드시 **자기 탭을 새로 열어서** 보고, 끝나면 닫는다.
  2. 공식 문서: `https://elevenlabs.io/docs/llms.txt` (전체 색인), `https://elevenlabs.io/docs/openapi.json`
  3. 대표실 앱 관찰 메모: `shared/research/elevenlabs/00-ceo-app-notes.md`
- **금지 (사용자 계정 보호)**: 생성·변환 버튼 실행(크레딧 차감), 음성 클로닝 생성, 마이크 녹음 시작, 파일 업로드, 결제·구독·설정 변경, 비밀번호 입력. 꼭 실행해 봐야 하는 단계가 있으면 하지 말고 보고서에 "실행 확인 필요"로 적어 대표에게 올린다.
- 기능 로직만 파악한다. 브랜드명·문구·UI 그래픽·코드를 베끼지 않는다.
- 짐작 금지: 직접 확인한 것만 쓰고, 확인 못 한 것은 "확인 못 함"으로 적는다. 출처(URL 또는 앱 화면 경로)를 단다.
- 산출물은 `shared/research/elevenlabs/` 아래에 저장하고, 끝나면 `shared/reports/<팀ID>.md` 맨 위에 요약(5~10줄)과 파일 경로를 추가한다.

## [2026-11-21 사용자 방향 전환 — 즉시 적용] 판매 안 함, 사내 전용
- 사용자 결정: 이 제품은 **판매하지 않는다. 우리 회사만 쓰는 사내 도구다.** 음성 모델은 자체 모델을 쓰고, LLM이 필요한 부분은 Claude API 크레딧으로 처리하는 방향을 검토 중이다.
- 따라서 판매 관련 작업을 **모두 중단한다**: 가격·원화 단가·손익분기, B2B 물량, 시장·포지셔닝, SLA·리전 비용, 요금제·크레딧 판매 설계.
- 새 지시가 올 때까지 대기한다. 진행 중인 판매 관련 문서는 지금 상태로 두고 더 고치지 않는다.

## [2026-11-21] 2단계 — 사내 전용 MVP 재정의
**전제(사용자 확정)**: 판매 안 함, 우리 회사만 쓴다. 음성은 이 PC의 CPU에서 자체 모델을 돌린다(GPU 없음 → 클로닝·고품질은 느릴 수 있음). 텍스트는 Claude API를 쓴다. 비용 0원이 목표다.
**산출물**: `shared/research/elevenlabs/01-planning-internal-mvp.md`
- 사내 사용 시나리오 제안(누가, 무엇에 쓰는지 3~5개. 사용자 확인용 질문 형태로)
- ElevenLabs 기능 지도(§2~§4)를 사내 기준 P0/P1/P2로 다시 분류. 판매용 기능(과금, 워크스페이스, 라이브러리 수익화, 마케팅용)은 제외한다
- 기능마다 "음성=로컬 모델 / 텍스트=Claude API" 중 어디서 처리하는지 표기
- DevOps CPU 실측 결과가 나오면 P0를 최종 조정한다
**마감**: 2026-11-22 18:00 (실측 반영본)

## [2026-11-21] 사용자 답변 (§1 질문) — 확정
- 시나리오: S1 영상 내레이션, S2 녹음 받아쓰기·요약·자막(번역 포함), S3 보고서 음성 브리핑, S4 대표 본인 목소리 복제. 모두 사용한다.
- Claude API: 이미 보유한 크레딧 안에서 쓴다. 싼 모델(Haiku) 위주로 쓰고 캐싱으로 아낀다.
- 사용자: 대표(사용자) 1명이 이 PC의 브라우저 화면으로 쓴다. 다중 계정·권한은 필요 없다.
- 결과물은 외부(고객·SNS·유튜브)에 공개한다. AI 생성 안내 표시와 "동의받은 목소리만 복제" 규칙을 넣는다.
→ 이 답으로 01-planning-internal-mvp.md를 확정하고, 실측이 오면 P0를 조정하라.

## [2026-11-21] 결정 회신
- ① 동의 기록 보관: 목소리 모델이 있는 동안 보관하고, 목소리를 지우면 1년 뒤 삭제한다.
